# 18 行业需求和单位生产成本冲击

这两组实验展示合成参数下完整模型的联合响应。使用[冻结政策复验](17_frozen_policy_reaudit.md)发布的修正版主政策。P、F 和价格溢价均以归一化价格计，数量及产能也沿用模型归一化单位。图表可用于说明时点与反馈机制，无法据此推断真实碳酸锂价格的变动幅度。

## 冲击与时点

`zA_id` 和 `zm_id` 在外生状态向量中的零基索引分别为 4 和 5。两者的创新载荷都是 0.00025，状态持续系数分别为 0.53 和 0.55。需求规模 A（以及 A_s、A_c）乘以 exp(zA_id)，单位生产成本 m 乘以 exp(zm_id)。同一条件下，+1 相对于该状态转移的 AR 位置乘以 exp(0.00025)，即直接乘数约增加 0.025003%。+1 和 −1 的直接比例为 exp(0.0005)。

第 0 月是冲击实现后的第一次决策。先对冲击前状态调用政策一次，再执行同一状态转移。每个起点和每一类冲击完全枚举其余八维当期创新的 256 种组合，对每种组合分别令目标创新等于 +1、−1。两条路径在第 1 月起共用同一随机序列，目标创新也在每一期按原 ±1 分布重新抽取。

正、负条件均值记为 M_plus、M_minus。随机基准为两者的等权平均，图上正向响应等于半个配对水平差 (M_plus−M_minus)/2。等概率定义决定反向响应恰为正向的相反数。跨起点比较的是不同状态下同一条件响应。

三组冲击前状态是确定性锚和上轮已审核路径中的两个实际状态。后两者事先取最长档预热索引的首尾，原路径编号为 2、254，均从对应根状态用保存的冲击重放 48 个月确认。所有起点及重放记录见结果目录的 `starts.json`。

## 估计精度和验证

[实验设置](../configs/stochastic_girf.json)预定每个初始组合先用 2、再用 8 和 16 条独立未来轨迹，每种冲击与起点的配对数依次为 512、2,048 和 4,096。需求与成本的后续抽样种子分别为 94852203、94852219。不同起点共用相应冲击的抽样，以便比较。误差带是以初始组合分层计算的约两倍蒙特卡洛标准误。第 0 月已完全枚举，蒙特卡洛标准误为零。

使用同一冻结多项式预测所有当期与后继决策。条件均值、方差和价格溢价按联合冲击核精确积分，不接入外部价格预测。所有模拟状态检查原始残差、经济可行性及近似盒。预设月 0、1、3、12、36、60，每类冲击与起点固定取第一个重复中的第 0 和第 255 个初始组合，正负路径都用原标量验证接口逐枝检查 512 个后继。终点诊断比较末五个月与全程峰值及积分误差，显著超过峰值的 1% 且超过绝对数值底限才延长至 120 月。

风险溢价定义为 E[P′]−F。CSV 同时保存按 E27 右侧算出的风险补偿作为数值交叉诊断，另有净套保敞口和条件价格方差。两种溢价算法之差提供了本实验分辨极小响应的参考，蒙特卡洛误差带只描述积分误差。

## 实际结果

在锚点，需求冲击先增加可灵活调整的耗用，当月货物由减少期末库存平衡。需求规模的直接上升超过了期货涨价对采购的压制，新采购承诺增加。单位成本冲击不从需求规模进入，采购承诺随期货涨价小幅下调。成本组在第 0 月，折现且扣除损耗后的持货收益增加量略高于现货涨幅，对应库存先小幅上升，之后转为减少。

| 锚点变量 | 需求冲击第 0 月 | 成本冲击第 0 月 | 后续响应 |
|---|---:|---:|---|
| 现货 P | +1.8130e-4 | +5.3017e-6 | 需求组第 0 月峰值，成本组第 4 月峰值 |
| 期货 F | +1.6808e-4 | +5.6516e-6 | 需求组第 0 月峰值，成本组第 3 月峰值 |
| 产量 Q | 0 | 0 | 第 3 月开始随产能变化，绝对峰值均在第 5 月 |
| 库存 I | −1.6732e-4 | +1.0835e-6 | 需求组第 2 月最低，成本组随后转负并在第 7 月最低 |
| 新开工 J | +8.2391e-5 | −1.1768e-5 | 两组最大绝对幅度都在第 0 月 |
| 有效产能 K_e | 0 | 0 | 需求组第 5 月 +8.5966e-5，成本组第 5 月 −8.8297e-6 |
| 新采购承诺 C | +5.6675e-5 | −3.8502e-7 | 承诺进入下一月耗用 |
| 风险溢价 E[P′]−F | −8.82e-12 | −1.41e-13 | 微小水平差，见精度诊断 |

两个预热起点相对锚点的主要变量曲线差距，最大约为对应锚点绝对峰值的 0.21%。需求组和成本组的风险溢价变化幅度远小于各自的期货价格变化，主要的价格响应与预期现货方向和时点一致。成本组锚点的第 0 月溢价变化，用 E27 右侧得 +1.65e-13，方向与直接差分相反。需求组的个别预热起点也存在与信号同量级的差异。图如实保留 E[P′]−F，溢价方向和跨状态差异只作诊断。

两组共检查 2,998,272 个访问状态，最大归一化原始等式残差 3.93e-11、最大对偶违反 3.64e-11。147 个预设状态（含 3 个冲击前起点）逐一枚举了 75,264 个后继，均通过原验证。访问到的最大近似盒归一化半径为 0.931，无物理或几何越界，也无超差样本。显示变量最后两档的响应最大变化约为峰值的 0.8%，低于预设 2%。第 60 月已达到预设消退标准，无需延长。项目一致性、条件市场、全条件检查及 50 项单测均通过。

## 复现与文件

从工作树根目录运行，使用新输出目录。环境见 [实验依赖](../requirements-girf.txt)，单页 PDF 使用 Windows 中文字体。

~~~powershell
python -m pip install -r requirements-girf.txt
python scripts/run_stochastic_girf.py --output results/stochastic_girf_reproduction
python scripts/plot_stochastic_girf.py --run-dir results/stochastic_girf_reproduction
python scripts/render_girf_brief.py --input docs/presentations/girf_brief_zh.json --output results/stochastic_girf_reproduction/meeting_brief_zh.pdf
~~~

先按第 17 节复现并保存相同的冻结政策、参数、核验报告和预热索引。实验会校验相应文件的 SHA-256，并将代码版本、策略与配置摘要写入 `provenance.json`。

`response.csv` 每行是一种冲击、一个起点、一个月和一个变量，含两个条件水平、基准水平、配对响应及标准误。绘图用原始水平差。各档增样误差见 `sampling_stability.csv`，各类残差与经济可行性见 `simulation.json` 和 `explicit_512_checks.json`。每种冲击的完整抽样索引在 `months_60` 目录下。若出现超差，路径及冲击全程另存，保留在统计中。
