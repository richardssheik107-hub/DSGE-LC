## 2. 文献家族不能混为一种证据

| 家族 | 主要回答 | 不能自动回答 |
|---|---|---|
| 系统动力学SD、多主体仿真 | 反馈、延迟、情景与主体规则如何产生路径 | 某条月度因果弹性是否由历史数据识别 |
| 动态物质流MFA/SFA | 某商品/元素如何流动、存留、报废与回收 | 市场价格如何在主体决策中出清 |
| 技术经济分析TEA | 指定工艺、地点和核算条件下的投入/成本 | 当期短期边际成本、实际利润或均衡价格 |
| 中央规划者优化 | 给定需求和目标下如何配置生产/投资 | 分散企业的均衡行为或实际政策效果 |
| PE/MCP市场均衡 | 主体最优化、约束与市场清算如何同时满足 | 默认可用线性Kalman估计、或自动成为完整CGE |
| CGE | 产业、要素、收入、贸易与账户一致的共同均衡 | 只靠5条产业观测即可校准/识别全部账户 |
| 计量识别/储存理论 | 哪些条件区分冲击、参数，约束如何改变动态 | 签上理论文献就证明自己的具体假设成立 |
