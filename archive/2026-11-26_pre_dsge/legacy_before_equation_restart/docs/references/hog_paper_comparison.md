## 1. 应借鉴的是研究逻辑，不是复制结果

参考稿的组织是：引言与产业背景 → 文献 → 四部门理论与主体行为 → 混频状态空间和MCMC → 参数/IRF/方差分解/预测 → 结论。其价值在于把产业机制、不同频率观测和动态冲击放在统一框架中。碳酸锂论文可以沿用这一逻辑，但必须明确自己的实际边界。

## 2. 修改稿中需要向作者核对的事项

以下是对“当前提供版本”的核对，不推断作者代码、最终发表稿或研究诚信。

### 2.1 表4与正文参数数值不一致

第21页表4中资本份额alpha均值为0.1208；表后正文写0.5496。期货参数和部分持久性/冲击尺度的正文也未与表逐项一致。碳酸锂项目应以自己的参数注册表/输出为准，不能直接复制这些数值作先验或校准。

### 2.2 抽样总数与ESS需要区分

第19—20页写两链、每链5000、各丢1000，又写“最终4000个有效后验样本”。若指两链合计保留draw应为8000；若指单链保留数或ESS，须明确。不能将raw draw count与有效样本量混用。

### 2.3 Theil公式与随机游走比较需要核对

第27页公式(42)从Word数学对象核对为：

`U = RMS(y_hat - y) / [RMS(y_hat) + RMS(y)]`。

这个分母是两序列的RMS之和，不是随机游走预测误差。根据三角不等式，该指标通常本就在[0,1]，所以仅有`U<1`不能推出优于RW。碳酸锂仓库所用 `U2=RMSE(model)/RMSE(RW)` 是不同指标；只有同目标同样本的U2<1才表示该误差指标上优于RW。

不得直接拿参考稿U=0.0924与本项目U2比较优劣。

### 2.4 “随机周期内生化”和时变频率的措辞

第16页给出固定频率参数lambda_c与阻尼参数rho_c的二维旋转过程，同时称时变幅度和频率。随机扰动能改变实现路径，但固定lambda并不自动成为显式时变频率模型；把周期放入状态方程也不等于从投资/最优生产行为推出内生周期。碳酸锂扩展应明确是统计周期还是行为机制生成的周期。

### 2.5 高频状态推进与低频变量观测

第10—11页的文字频率与表2观测数需要按变量逐项核实，例如居民收入仅4个观测，不能把其在平台上可下载的日历展示当成日度新增信息。参考稿17页将低频值在月末更新；对碳酸锂，必须额外区分统计月份和真实公布日。

低频库存是存量、产量/装车是期间流量、月均价格是平均值，观测矩阵所需聚合不同。不能仅把月度流量放到某一天而不说明与高频状态的聚合关系。

### 2.6 高预测精度是该稿报告结果，不是本项目目标

参考稿报告期货方向准确率95.33%、周期FEVD89.50%（28页等）。仅凭稿件无法核实其全部训练/预测时点、估计窗口、是否使用滤后还是预测状态、标准化范围及原始代码。因此只记为“文献报告”，不作为本项目验收线，也不据此指控信息泄漏。

## 3. 碳酸锂论文的独立贡献应怎么写

建议写为：在有限、口径一致的产业观测下，建立可审计的需求—成本—供给—供需压力—价格变化半结构模型；量化参数/结构响应的不确定性；结合历史分解、递归历史OOS、物理库存/成本构念比较与独立期现分析，讨论哪些机制得到支持、哪些仍弱。

不要写为“复制并改进了全部四部门混频DSGE”“首次填补国内空白”“已识别投机”“基本面完全解释价格”。与参考稿的区别是模型范围与证据安排不同，不是单靠代码数量、链长度或测试数量宣称优越。

## 4. 理论补强的推荐顺序

1. 首先写清现有五条方程的产业依据、状态单位、先验符号与未识别含义，修正同比/日差分和库存指数解释。
2. 经导师确认保留半结构路线；若导师要求完整DSGE，再明确必须补的目标函数、约束、稳态、均衡求解和观测映射，并单列成本与时间。
3. 优先增加同口径库存测量或可验证的慢供给机制；一次只改一个识别缺口。
4. 混频和联合期现作为可选专项；Harvey周期/非线性不作为毕业默认任务。
