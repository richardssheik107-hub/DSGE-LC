# 一分钟中期研究摘要

> 修订日期：2026-09-16（研究修正版 R1）；范围：诊断、FEVD/历史单位、期现同口径、预测/外部验证措辞；旧版定位：Git `ef2eb37`。数字以 R1 审计为准，文献与导师/学校验收未完成。

我的论文研究碳酸锂价格波动。用2020年1月至2025年9月的冻结数据，我估计了月度五状态半结构模型，实际结构样本57个月；R1重新核验原七套后验，均通过修正后的数值诊断，未重估。

成本仍是相对最稳定的基本面通道，但12个月价格FEVD的可加总后验均值中，价格残差约占64.9%。历史分解显示上行期成本贡献较大、2023年成本与残差均负向；后期跨规格解释有歧义。结构点预测仅一月期优于随机游走，均未胜BVAR。库存水平关系有有限支持，变化量证据弱；期货日频+1相关保留，修正后的月频峰值转为同期。

这些都是给定模型、短样本下的条件证据，不是因果证明或真正前瞻检验。文献核验、导师确认和未来新增数据验证仍待完成；当前模型不是完整DSGE或已实现混频。
