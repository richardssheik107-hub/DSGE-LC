# 硕士学位论文长篇结构建议

2026-09-19｜结构建议，不是学校模板、固定章数或最低篇幅要求。

本论文从新问题和新模型组织，不要求把 R3 短稿扩写成毕业论文，也不要求旧 M0 成为正文基线。建议先用下列九个内容单元安排写作，可因理论深度把一单元拆两章，也可合并相近结果章。正文长不等于必须更大模型；长度来自完整文献论证、推导、资料、识别、检验和限制。

| 建议单元 | 本章应回答什么 | 应形成的证据/内容 |
|---|---|---|
| 1 绪论 | 为什么研究、具体问题、论文边界及贡献是什么？ | 主问题、研究路线、可验证贡献，不写“首次”口号 |
| 2 文献与理论基础 | 各机制已有研究怎样处理，本文继承/改变什么？ | 产业、需求、成本、投资、储存、结构识别的原文比较；不是工具简介合集 |
| 3 产业机制与数据特征 | 商品、路线、用途、统计口径和关键动态是什么？ | 产品/时点/单位与数据字典、描述事实、覆盖和缺项，不把代理当实物量 |
| 4 主体行为与动态模型 | 生产、耗用、被选中的投资/储存怎样闭合？ | 目标、约束、最优条件、时序、稳态、角点、模块增删；必要时拆为基础和扩展两章 |
| 5 状态空间、观测与估计设计 | 怎样从经济方程进入数据和后验？ | 状态/控制区分、解、观测算子、参数归一化、先验与识别、合成恢复、信息集 |
| 6 新模型估计与动态解释 | 哪些参数可识别，冲击怎样传导？ | 真实后验、状态、IRF/FEVD/HD和不确定性、初始条件与解释边界 |
| 7 机制对照与稳健性 | 新增机制是否必要，结论依赖什么？ | 同窗口/同观测可比设计、逐机制变化、弱证据/失败规格，不为了好结果筛模型 |
| 8 预测与外部检验 | 模型能否解释样本外对象，是否有外部信息支持？ | 递归预测与基准、数据发布时间、外部测量核验；期货信息仅在选定时加入 |
| 9 结论与研究局限 | 回答主问题到什么程度？ | 有证据的结论、假设敏感性、数据/方法局限和后续方向；不把模型情景当政策因果估计 |

附录可以包括：完整方程及符号、文献原式对照、工程转换、数据可得日与版本、先验和参数表、均衡求解与识别细节、额外对照、复现说明。结果主源应统一注册，不在多个稿件手抄数字。

## 写作节奏

RB01即可写绪论问题稿和文献卡；RB02—RB04逐轮写理论章与附录；RB06写数据/估计方法；RB07之后才写真实参数和结果段。未产生的实证以任务台账管理，不在正文填“预期发现”。

新主稿建议在范围确认后创建 docs/thesis/masters_rebuild/ 分章工作区；现在只有结构和讨论材料，不声称新毕业论文正文已经完成。R2/R3及旧九章稿作为历史档案，不再要求同步修改。学校正式模板、字数、格式、AI声明及提交日期待核，不从参考稿作者院校推断用户院校。
