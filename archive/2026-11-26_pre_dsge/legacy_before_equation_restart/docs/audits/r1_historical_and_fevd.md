# R1-2：历史分解门槛与 FEVD 加总审计

日期：2026-09-16。修订运行目录：`outputs/revisions/R1_20260916_190253/`（本地忽略，不覆盖旧 Phase 2E/2F 文件）。本轮只复用 R1-1 已验收的七套 production posterior；未重跑 MCMC，未改变 M0_CORE5 方程、观测、先验或 Data Freeze。

## 预登记定义与门槛

门槛在读取本轮历史敏感性结果前固定于 `configs/r1_revision.json`：七套规格、子样本参数中位数偏移最大 0.10 个 full-posterior SD、5%/95% 尾部分位偏移最大 0.25 个 SD；主导冲击后验概率至少 0.75 且活动份额变化超过 0.20 才能构成“主导者实质替换”的 HIGH 证据；核心冲击 90% 区间在零两侧清晰反向亦触发 HIGH。原 `configs/phase2f.yaml` 的固定窗口、seed 20260915、等链 1,000/250 抽样与 2,000/500 预设回退保持不变。未为任何规格改 seed、调阈值或挑窗口。

技术有效性、统计/经济敏感性、下游解释许可分开判定。`HIGH` 是可交付的研究发现，不是数值失败；`AMBIGUOUS` 也不被美化为稳定。`NOT_EVALUATED`、缺规格、子样本 FAIL 或任何必要数值条件 FAIL 都阻止技术 READY。固定窗口为 2021-02—2022-12、2023-01—2023-12、2024-01—2025-09。

## 历史分解实现

对每个入选参数 draw，按原模型进行 Kalman 滤波、RTS 条件均值平滑，以满列秩 QR/LAPACK 最小二乘从状态转移残差求四类冲击，再分别递推初始条件与四冲击贡献。B 为 5×4；2021-01 仅有初始条件，2021-02 才有第一笔转移冲击。所有恒等式、窗口和路径累计在 float64 完成；绝对误差不超过 1e-8 **且** 相对误差不超过 1e-10，协方差最小特征值不低于 -1e-10。spot/state 的 1e-6 容差沿用 Phase 2F 配置。展示 CSV 经过十进制格式化，门槛施于未舍入数组，不要求 CSV 反算达到机器精度。

区间是“参数后验传播下的条件平滑均值区间”，不是包含 latent-state 模拟误差的完整状态区间。每个 draw 先完成月度贡献、窗口累计、累计路径和绝对活动份额，再取后验均值/分位数。主图用可加总的后验均值，将正负贡献沿零线上下分别堆叠；累计图取 `quantile(cumsum(draw path))`，不取 `cumsum(monthly median)`。窗口贡献可能包含此前冲击的持续作用，不应全部解读为窗口中新发生的冲击。

后验文件 SHA256 与 R1-1 认证表逐个比对；六个原 sidecar 与 R1-0 预检哈希比对，panel 与 Data Freeze 亦绑定。所有输入在计算前后再次比较；118 个旧 Phase 2D–I 输出哈希未变。baseline 缺少当时生成的 sidecar，仍沿用 R1-1 的 `PASS_RECONSTRUCTED` 证据及其限制，而非声称有原始 sidecar。

## 历史审计结果

七套规格的首次固定抽样均通过参数中位数和尾部代表性门槛；baseline 使用 4,000 draws（每链 1,000），其他每套使用 1,000 draws（每链 250），均无需回退。最大中位数偏移为 0.09494 个 SD，最大尾部分位偏移为 0.19746 个 SD。每套的完整 14 参数偏移、抽样索引 SHA256、posterior 文件 SHA256 均见 `historical/historical_subset_audit.csv`。

七套 Kalman/RTS、B 秩、协方差、冲击重建、逐 draw 与窗口恒等式、spot/state identity 均通过。最大冲击重建误差 5.33e-15、状态分解绝对误差 3.02e-14、窗口恒等式误差 2.49e-14、基线逐月后验均值加总误差 1.86e-13；最小平滑协方差特征值 -5.01e-29，属浮点舍入尺度且高于预设 -1e-10；最大 spot/state 差 2.22e-15。`historical_gate_details.json` 的 7×9 必要技术检查全为 true、failures 为空，20 个输入文件运行前后哈希一致。旧输出未被作为新的 PASS 依据。

18 个替代规格×窗口组合的分类为：10 `STABLE`、2 `MODERATE`、6 `AMBIGUOUS`、0 `HIGH`。六个 `AMBIGUOUS` 均出现在 2024-01—2025-09 窗口；两项 `MODERATE` 为 `BATTERY_SD_010` 与 `RHO_N_095` 的 2021-02—2022-12 窗口。技术有效性可通过，但 `DOWNSTREAM_INTERPRETATION_GATE=INTERPRETATION_REVIEW_REQUIRED`；不能不加限定地声称历史主故事对规格稳健。每行的区间、冲击活动份额及主导概率在 `historical_story_sensitivity_corrected.csv` 的 `evidence_json` 中，而不是只提供标签。

基线的窗口净贡献和绝对活动份额见 `historical_episode_corrected.csv`。2021–22 上行窗口的成本冲击后验均值净贡献约 +7.766、价格残差约 -3.396；2023 下行窗口两者分别约 -4.521、-3.755；2024–25 窗口价格残差约 +4.657，但负向需求/成本/供给同时存在。它们是标准化价格变化压力的模型分解，并非人民币价位、利润或因果政策效应。残差贡献大是解释边界，不是调模型或强行转为数值 FAIL 的理由。

## FEVD 审计

冻结冲击矩阵 B 已包含各冲击标准差与同期价格传导；按每个 production draw 的 `A^h B` 结构列平方和计算 1、3、6、12、24 个月 FEVD，**不**重复乘 sigma、不做 Cholesky 二次正交化、不增设电池测量冲击。七套原后验全量参与：每链 draws 为 18,000／48,000／18,000／42,000／18,000／24,000／36,000，各有四链。逐 draw 验证非负方差贡献、正分母单元份额范围及和为 1、`W=BB'` 预测误差协方差对角线；价格状态分母单独要求正数。

修订汇总有 700 行（7 规格×5 horizon×5 state×4 shock），审计有 175 行（7×5×5）。其中 168 单元 `PASS`；七套的 H=1 库存状态没有同期冲击方差，正确标为 `ZERO_FORECAST_VARIANCE/NOT_DEFINED`，对应 28 个 shock 份额为 NA、不是四个零，也不是程序失败。没有 `FAIL`。最小价格方差分母 0.339456；最大逐 draw 份额和误差 4.44e-16、后验均值份额和误差 8.02e-14、协方差对角线误差 2.56e-13，均低于预定 1e-10。FEVD 的 20 项数据/配置/A01 输入文件在运行前后 SHA256 完全一致。

基线 12 个月价格 FEVD 的四个**逐 draw 份额的后验均值**依次为需求 0.089121、成本 0.212966、供给 0.049015、价格残差 0.648897，合计 1。四个边际中位数依次为 0.071252、0.202190、0.038343、0.652723，合计 0.964508；这不是“漏掉 3.55% 冲击”，也不得把中位数归一化后冒充后验量。`fevd_corrected_summary.csv` 同时保留各边际 5%/95% 与 16%/84% 区间。主堆叠图使用可加总的后验均值，已目视检查。历史分解的“绝对活动份额”与 FEVD 方差份额是不同统计量，不应拿两者数值大小直接判定矛盾。
