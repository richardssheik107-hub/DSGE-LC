## 怎样使用冻结基线

通常只阅读当前 [DSGE方案](../../docs/03_dsge_blueprint.md)。确需核验时进入 `frozen_pe_20261118/`，执行其四项轻量检查。目录结构整体保留，因此原 `from model...`、配置和文档相对路径仍在本快照内解析。

需要复用的建设队列、KKT、原始残差审计或配对GIRF方法，应复制到新的命名空间并记录来源；新增家庭SDF、财富或预算后必须重新推导相应条件。不得直接把旧7+L+R条件数、17维状态、三类MV定价或已发布冲击图挂到新DSGE上。

归档旧数据生成脚本只能作为方法历史；不得默认执行，因为部分脚本会把工作簿逐期实值写回公开报告。默认仓库检查只核对清单和哈希，不导入或运行历史经济代码。
