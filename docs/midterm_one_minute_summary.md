# 一分钟中期研究摘要

我的研究关注中国碳酸锂价格为什么会快速上涨、下跌和持续震荡。基于2020年1月至2025年9月的冻结数据，我构建了一个包含需求、成本、短期供给、库存压力和价格压力的半结构状态空间模型，并完成Kalman滤波、约束MLE、Bayesian MCMC、脉冲响应、方差分解、历史分解、严格样本外预测和期现扩展。

目前最稳定的结论是成本通道。模型中需求和成本冲击推高价格，供给冲击压低价格；2021—2022年成本是最大的正向结构贡献，2023年成本是最大的负向基本面贡献。结构模型在一个月预测上优于随机游走、在三个期限都优于普通VAR，但没有击败BVAR。潜在库存与实物库存方向一致，GFEX期货也提供了领先后续现货变化的初步信息。

这些结果仍受57个月小样本、弱参数、固定库存持续性、较大价格残差、短OOS和短期货历史限制。中期后我将首先用2026—2027年真实新增数据做前瞻样本外检验，再决定是否扩展慢产能、混频或非线性模块。
