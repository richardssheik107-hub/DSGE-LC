- 出版社/作者机构元数据与摘要：只能支持主题、机制和出版信息；不能登记原式已核。

- 原机构搜索索引正文：可核到返回的条款或正文，但应记录直接打开失败，不能宣称完整现行制度审计。

## 3. 期现关系最直接的原式及版本对应

ELV19的期刊书目为 Ekeland、Lautier、Villeneuve，*Economic Theory* 68:83–123（2019），DOI [10.1007/s00199-018-1115-y](https://doi.org/10.1007/s00199-018-1115-y)。本轮核到两份公开作者稿，不能混用式号：

| 作者稿版本 | 已定位关系 | 适用页码 |
|---|---|---|
| [2017-04-26稿](https://www.ceremade.dauphine.fr/~ekeland/Articles/ELV%20Final.pdf) | 三类聚合持仓式(8)—(10)，清算/溢价式(13) | 该稿§3.3—3.4，印刷pp.7–8 |
| [2018-01-26稿](https://www.ceremade.dauphine.fr/~ekeland/Articles/ELV.pdf) | 均值—方差式(6)，持仓/实物式(7)—(11)，溢价式(16)，闭合系统(17)—(19) | 该稿§3.3—3.5，印刷pp.6–9 |

两个版本支持共同的结构：三类头寸＝各自实物套保头寸＋风险承受份额；期货总头寸清零后，预期现货与期货之差由净卖出套保敞口及总风险承受能力决定。本文令库存敞口为损耗后的alpha_I I、采购敞口为C，并自行加入折现、服务、月度滚动和能力投资。ELV的原式与定理没有自动验证这些新增部分。

Baker的[2019-04-05作者稿](https://stevendbaker.com/papers/baker_oilSpeculation.pdf) §2.2，印刷pp.11–12，式(4)—(8)提供联合目标与库存边界的另一直接依据。其逐期利润选择和公共信息假设应保留在适配边界说明中；作者稿页码不是2021期刊版页码。

## 4. 哪些仍是本文函数，不能借文献权威省略验证

| 当前设定 | 性质 | 最小验证或受限基准 |
|---|---|---|
| 常弹性净收益与s/c分组 | 本文聚合函数和时点假设 | 耗用与排产资料约束eta_s、eta_c、omega；总弹性需按分组权重映射 |
| 幂次负荷Q^(nu+1)/K^nu | 本文成本曲率 | 工程成本和有效能力观测；nu=1作嵌套比较，不直接等于供给弹性倒数 |
| omega_B J X^B | 本文在建拥挤 | 首个求解基准omega_B=0；保留时查跨期凸性充分界与项目证据 |
| 固定L、R与g向量 | 项目异质性的聚合近似 | 区分矿山开发和锂盐加工扩建，分别记录开工、首产和达产 |
| hI−xi log(1+I/I0) | 本文净持有成本 | 正偏移允许零库存；查严格有界性与库存服务依据 |
| 无财富效应的进入/退出 | 一期目标的动态嵌入假设 | 不称完整长期风险厌恶优化；保证金/财富扩展须改目标和状态 |
| 无基差单期合约 | 便于风险分配的合同简化 | 冻结实际交割/结算观测映射后再决定是否扩展协方差 |
| 有界创新和紧工作域 | 计算基准与待验收政策空间 | 后继状态几乎处处可行、有限矩和无泡沫条件不能由有界创新直接推出 |

本轮新增的库存完整边界、条件市场唯一性、跨期开工凸性界、无除方差分配和无期货FOC均为[本项目数学推导](10_closure.md)，不登记成某篇文献的原式。

因此E26仅定义模型的h(P'−F)支付。不能把行业月均现货P直接当真实交易所交割结算价，也不能把合约表最低保证金当样本期所有合约的实际标准。已找到2026修订线索但未读到完整官方附件；本轮不宣称完成全部现行合约规则审计。数据验收应逐合约记录适用规则版本、期限、品级、地点和结算方式。

若引入真实结算标的S及未套保随机收益X_i，则均值—方差FOC会出现Cov(X_i,S)，不再自动消去基差和随机成品收益。必须重新推导E23/E24，不能在旧完美套保系统上机械叠加修正项。
