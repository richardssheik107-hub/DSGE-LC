# 三分钟中期研究摘要

我的论文题目是《碳酸锂价格波动的影响因素与定价机制研究》。研究想回答三个层面的问题：第一，需求、成本、供给和库存如何共同影响碳酸锂价格；第二，这些结构力量如何解释2021—2022年的上涨、2023年的下跌和之后的调整；第三，结构模型在严格样本外和期货市场中能否得到额外支持。

数据方面，我冻结了2020年1月至2025年9月的69个月核心样本，包含SMM电池级碳酸锂现货、碳酸锂产量、SC6锂辉石价格、动力电池装车和汇率。由于数量变量使用同比变化，结构样本为2021年1月至2025年9月，共57个月。社会库存和路线生产成本不进入估计，只用于外部验证；GFEX期货构成单独的初步扩展。

方法上，我先完成平稳性、领先滞后和断点诊断，并建立RW、AR、VAR和BVAR预测基准。随后构建五状态半结构线性状态空间模型，状态包括需求、成本、短期供给、库存压力和价格压力。模型通过合成参数恢复、32起点真实MLE和四链Bayesian MCMC审计。基线后验的最大R-hat为1.0079，最小bulk和tail ESS为627.9和484.2，达到预设收敛标准。

结果方面，成本到价格的参数和外部证据最稳定。需求和成本冲击提高价格，供给冲击降低价格，这些方向在六套替代后验中没有反转。12个月价格FEVD中，成本、需求和供给份额约为20.2%、7.1%和3.8%，价格残差约65.3%。因此成本是最强基本面机制，但不能说成本完全解释价格，也不能把残差直接解释为投机。

历史分解显示，2021—2022年成本净贡献约+7.759，需求约+3.727；2023年成本约-4.578，价格残差约-3.763，需求约-2.534；2024—2025年负向基本面被约+4.611的正向价格残差部分抵消。这是条件平滑状态均值下的模型分解，不是因果证明。

严格结构样本外预测中，H1、H3和H6的Theil U2为0.914、1.240和1.131。结构模型H1优于随机游走，三个期限都优于普通VAR，但没有击败BVAR。外部验证中，潜在库存与实物库存相关约0.650，方向稳健但幅度受`rho_n`影响；成本状态与锂辉石路线生产成本变化相关0.988，但有一定机械成分。

期货扩展使用36个GFEX五分钟合约，按当日成交量构造无未来信息的主力序列，并采用roll-safe收益。月频和日频相关均在期货领先一期时达到峰值，提供初步领先证据；但价格层级没有通过一阶单整门槛，因此没有强行做协整或VECM。

当前核心实验已经冻结。主要限制是结构样本只有57个月、`a_c`与`b_n/b_q/rho_p`等方向较弱、需求对Battery测量假设敏感、价格残差仍大、OOS和期货样本较短。中期后的首要工作是真实未来OOS和新的Data Freeze版本，再根据新增证据决定是否加入慢产能、改进库存观测或扩展混频模型。
