# 三分钟中期研究摘要

> 修订日期：2026-09-16（研究修正版 R1）；范围：后验诊断、FEVD/历史分解和单位、期现收益、OOS 与外部验证；旧版定位：Git `ef2eb37`。相关图表须采用 R1 审计版本；文献、导师与学校验收尚未完成。

我的论文研究碳酸锂价格波动：基本面如何对应价格，上涨与下跌如何在模型中分解，预测和期现数据能否提供额外支持。

冻结数据有69个月，结构样本57个月；库存、路线成本未入似然，期货是独立扩展。

我先建立随机游走、AR、VAR和BVAR基准，再估计五状态月度半结构模型。原现货与矿价标准化用68期拟合，同比两列用57期；四列都是月度，并非混频。R1未重估后验，只修诊断：七套原draw均过门槛，基线bulk/tail ESS最低为621.49/482.27；基线来源为重建认证，不是原生sidecar。

成本是相对最稳定的基本面通道，但需求、供给数量识别较弱，模型内冲击方向也部分由方程规定。12个月价格FEVD的可加总均值：需求8.9%、成本21.3%、供给4.9%、价格残差64.9%；边际中位数不能相加，残差不等于投机。

条件历史分解显示，上行期成本贡献较大，2023年成本和残差均负向；后期六个替代规格—窗口解释有歧义。图中原为标准化变化压力，换回原始log须乘旧标准差、再加确定性均值，不能写成单个冲击的元/吨或可加总百分比。

递归历史样本外预测仅一月期胜随机游走，三期限均胜普通VAR、均未胜BVAR；这不是真正前瞻或完整实时检验。库存log水平相关约0.650，变化量证据弱；路线成本相关约0.988，主要有共同矿价成分，非独立验证。

旧月频期货领先一期相关0.710有聚合错配；同端点后约0.526—0.528，峰值转同期。日频+1约0.473—0.475仍在，但主力规则、短样本和报价时点限制了价格发现解释；协整门槛未过。

本轮也保留不利于原叙事的证据：18个历史规格—窗口对照中有10个稳定、2个中度敏感、6个歧义；没有HIGH并不等于后期行情解释稳健。原库存相关的窄区间只反映给定参数draw的分布，新增3个月和6个月配对时间块检验后，库存变化量相关的区间都跨零。这说明技术计算通过与经济解释成立是两道不同门槛。我没有为恢复原结论而更换样本、删去规格或重估后验。

目前是有边界的半结构研究，不是完整DSGE。文献、导师确认和未来真正前瞻检验仍待完成。
