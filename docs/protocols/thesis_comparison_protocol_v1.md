# 学位论文深化：有限比较协议草案 v1

日期2026-09-17，科学基线 `0128c1aee9e553bc16ef2025ed4f29eaea3e9850`。**本文件是设计草案，不是已执行实验，不是回溯性“事前注册”。** 已经看过历史数据与R1结果；D02需在新比较结果产生前冻结设计commit、配置、测试和预算，再运行。任何修改保留旧协议并说明原因。

## 1. 要回答的三个问题

RQ1：供需压力状态是否提供不能由更小模型同样获得的信息？

RQ2：成本通道和主要历史解释是否依赖自主成本过程及测量尺度？

RQ3：在保守可得信息集下，期货资料能否改善随后现货报价预测？

本轮仅CMP_NOINV4、CMP_COSTFEEDBACK15、ROB_COMMON57和FUT_DAILY_INCREMENT。它们是平行的单因素比较，**不组合成NOINV+反馈+新scaler大网格**。基线不重估，除非需同信息窗口的合法预测重估或确认有真实实现错误。

- 后验沿用R1诊断：R-hat≤1.01、bulk/tail ESS≥400、mean MCSE/SD≤.05；四链。核验原生参数顺序，不把不同规格draw合并。

## 3. CMP_NOINV4：库存压力状态的增量

### 3.1 规格

状态[d,c,q,p]，观测[spot,ore_cost,output,battery]，创新仍为[demand,cost,supply,price]。删除n递推、b_n及无用rho_n；保留其余方程，价格为：

`p_t = rho_p*p_(t-1) + b_d*d_t + b_c*c_t - b_q*q_t + sigma_p*eps_p,t`。

自由参数13个。不是把旧posterior的b_n改为零；也不是保留一个与观测完全断开的n状态。H为4×4，必须按新索引构造，不走当前matrices.py的M0价格索引4。

### 3.2 验收与比较

在相同scaler、同一观测样本与同一likelihood约定下，比较约束MLE的LL、AIC/AICc/BIC、创新诊断、价格动态矩、可比冲击的IRF/FEVD、固定历史窗口及必要递归预测。AIC使用MLE的likelihood，不用MAP posterior objective替代。

因旧b_n=0处于参数支持边界，且涉及潜状态退化，不直接套常规卡方LR显著性，也不凭正先验下区间不跨零证明模型必要性。不使用未核验Bayes factor或后验最大值排序。

若更小模型表现相近，正确结论可能是压力块的额外量化信息有限；保留基线用于版本比较，是否用小模型作为最终主规格须写明判据并由导师审阅，不能静默换主结果。

## 4. CMP_COSTFEEDBACK15：自主成本假设

### 4.1 规格

只把成本过程改为：

`c_t = rho_c*c_(t-1) + eta_pc*p_(t-1) + sigma_c*eps_c,t`。

五状态、四创新、15自由参数，其他基线方程不变。eta_pc允许正负，不能通过正支持区间预置所需结论。D02前需写明尺度解释，草案默认 `Normal(0,0.25^2)` 截断到[-1,1]；这是设计选择，不是文献估计值或由旧MLE校准。若设计审核改变，只能在读取新真实结果前变更版本；不能因结果不稳而事后拓宽支持救模型。

成本当期依旧先于价格，反馈是滞后项，需重新推导A全矩阵，不能只改A的一格却漏掉价格方程对当期c的代入。B仍按顺序方程推导，冲击定义不做Cholesky二次替换。

### 4.2 解释

比较eta_pc后验、原成本loading、关键IRF/FEVD和相同历史窗口，报告有效先验被稳定区域截断的变化。允许反馈后仍不能说成本创新获得外生识别。若成本份额显著变化，结论改为对自主成本设定敏感；不把“份额保持最大”设成成功条件。

## 5. ROB_COMMON57：测量规范的独立版本

先复现LEGACY四列与68/57期scaler，再在共同57期上重新拟合每列。输出每列mu、sd、ddof、拟合日期、source hash及旧新差异；正式估计使用新measurement ID，绝不将新观测配旧draw。

固定loading、n中q/d系数和battery_sd使用标准化单位。重新定标可能改变原始单位下隐含噪声和先验，因此草案比较解释为“同一标准化建模规范下的尺度敏感性”，不是无条件的纯数值等价变换。D02必须写出原始单位隐含噪声的变化；若要求物理噪声完全一致，则另行推导联合state/loadings/prior映射，不临时增加第四个结构变体。

禁止跨不同测量尺度直接比较raw loglik/AIC大小。可比较相同实际价格尺度上的预测、还原后的动态对象与含义明确的参数变动；标准化参数大小不直接作为经济效应增减。如果报告预测密度，先核验变换Jacobian及同一预测对象。

当前共同57期仅构建的状态继续保留，直到新MLE/后验及其验收确实完成。不能把本轮计划视为A04旧任务失败，也不能称这项已经做过。

## 6. FUT_DAILY_INCREMENT：期货信息的预测价值

### 6.1 目标与时间

采用已核验的共同交易日索引。主目标：`Y_(t,h)=log(S_(t+h))-log(S_t)`，h为1和5个共同交易期；源S是SMM现货评估价，交易策略与现货可成交价不在范围内。

先定义预测事件时间。缺完整现货日内发布时间时，使用日终资料可得的近似，并将期货收益/基差至少额外滞后一个共同交易期作为保守主信息集。这个滞后不是已证明真实发布安全：记录可得性假设，仍称历史伪实时。更积极的当日期货信息只允许作单列时点敏感性，不拿来取代主结果。

从前250个完整对齐共同交易期形成初始窗口，之后expanding-window；250是预先选择的设计预算，不由预测结果优化。若缺失导致历史/评价不足则先出覆盖报告，不能降低窗口至刚好显著。原535个交易日只是旧窗口参照，不强制凑N。

**训练标签成熟规则**：在origin t拟合h期模型时，仅允许训练起点s满足其target_end(s,h)≤t且已公布。h=5时不能把最后5天尚未实现的Y放进训练。仅限制X日期≤t不够。保留origin、feature_available_at、training_label_max_end、target_start/end、missing reason。

### 6.2 小模型集合

- RW：未来log变化点预测为0。
- AR：直接h期预测，固定5个现货收益滞后和截距。
- ARX_F：AR加最近一期保守可得的换月安全期货收益。
- ARX_FB：ARX_F再加同源真实期货/现货的保守可得基差。

不再扫描大量AR阶数、机器学习模型或众多价量因子。回归有奇异/病态时明确失败；不根据测试期误差选择正则强度。若D02决定采用收缩以防数值病态，必须对AR和ARX一致并提前冻结，不边跑边改。

主力规则使用t-1成交量及可预知合约资格；换月收益比较同一合约两端点。基差来自真实价格而非后复权指数。保留t日成交量主力仅作事后描述，不当成前一日可执行选约。缺报价的多日区间不压缩为一天。

### 6.3 评价与推断

所有模型按同(origin,target,horizon)比较，失败不得无声删样本。主报告以累计log变化的RMSE/MAE及相对AR/RW误差为主；指数化点预测为单列价格误差，不无条件称E[P]，也不伪装盈利。

主对比ARX_F对AR，ARX_FB为预登记次要规格，h=1/5共明确检验族。嵌套模型不能不加审查地机械套普通DM星号；Clark–West调整需在估计/损失/渐近条件可辩护且独立合成size/power测试后才报告。多步重叠需保留相关结构，配对block-bootstrap/HAC仅在其条件写清时使用；若检验条件不满足，报告描述性误差差与限制，不造显著性。

Model Confidence Set只作方法阅读备选，不为增加工作量自动运行。选模型已经参考过历史数据，因此这里仍非真正prospective。效应不显著或没有增量也是可交付结论，完整保留四模型和所有期限。
