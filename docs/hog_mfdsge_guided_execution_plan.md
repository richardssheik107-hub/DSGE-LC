## 不改变的研究原则

产业机制先于模型复杂度；稀疏观测与潜在状态需要明确观测映射；诊断/识别/经济解释分别验收；参考论文方法可借鉴，数值结论不可作为调参目标。

## 纠正后的路线

既有月度M0闭环 → 独立诊断与口径修正 → 修正后中期冻结 → 真实前瞻检验与版本化扩样 → 有证据才做库存/慢供给或混频专项 → 最终论文。

当前`n`是标准化供需压力指标；需求增强使下一期n下降，不沿用旧示意图“需求增加使库存压力上升”的混淆。参考文献的流量/存量混频逻辑、Theil定义与稿件数值须先核对，不能照搬。
