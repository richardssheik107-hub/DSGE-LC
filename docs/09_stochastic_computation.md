# 局部随机均衡、组合选择与原条件审计

日期：2026-11-26。模型：LC_DSGE_EQCHAIN_20261126。方程唯一规范仍为[E01—E40](06_equation_chain.md)，组内生猪稿仍是主体组织和冲击传导的主要参考。本文报告新计算的范围，不替代规范或把历史PE结果接入新模型。

## 1. 本轮实际完成的层次

本轮求得**零库存、正投资、产能与债务/抵押约束松弛分支下的局部一阶随机理性预期政策**，并用领先二阶定价条件选择零阶期货组合。所有参数为合成归一化参数；未对中国数据校准或估计。

| 对象 | 本轮证据 | 结论 |
|---|---|---|
| 无风险锚与原条件 | 原17项验证；主锚最大残差约2.22×10⁻¹⁶ | 继续作为展开点，不能单独证明随机解 |
| 一阶动态均衡 | 17个状态、16个控制；17个稳定/中性根；最大线性方程残差1.11×10⁻¹⁴ | 当前局部分支的一阶政策通过 |
| 期货零阶组合 | 两个二阶协方差差异条件；缩放残差2.74×10⁻¹² | 零阶风险承担组合得到选择 |
| 有限期冲击响应 | 4个创新、0—36月；每份CSV共148行 | 可报告局部一阶条件均值响应 |
| 完整非线性条件 | σ=0.001下最大原条件残差3.69×10⁻⁵ | 线性候选不能作为精确非线性解 |
| 非线性投影 | 配点/外样本误差仍高于1×10⁻⁸；动态不稳定，随机路径违反抵押约束 | 失败候选被拒绝 |
| 长期财富与实证 | 3个受到创新激发的财富单位根；没有真实数据估计 | 不报告平稳无条件方差、FEVD或估计结论 |

机器记录见[随机求解验证](validation/local_stochastic_20261126.json)，局部政策和IRF见[输出目录](../results/local_stochastic/)。本轮30项测试包括原条件17项、shock审计4项、消元等价性3项和局部随机求解6项；测试通过不等于非线性候选通过。

## 2. 局部分支、状态和同一概率核

规范在L=3、R=2时有18个状态坐标。在严格零库存分支上，继承库存与当前库存都为零，因此局部系统用17个状态。这个降维只在该分支成立，不能删去规范中的库存状态。

当前局部求解还要求：新开工为正、产量低于有效产能、W/I/D借款下界松弛、F抵押约束松弛、各类消费为正。库存对偶差为正，因此库存取零符合KKT，而不是求解器将负库存截断为零。这里没有求约束切换后的其他分支。

四个外生状态保留

$$
z_{t+1}^k=\rho_k z_t^k+\sigma_k\varepsilon_{t+1}^k,
\qquad \Pr(\varepsilon^k=1)=\Pr(\varepsilon^k=-1)=\tfrac12.
$$

它们相互独立，下一期共有16种组合。完整原条件审计逐一计算16个后继的消费、价格、财富、贴现因子和影子价值，使用同一政策及转移规则。不存在每期重置F财富、以平均消费替代随机消费、以两套独立预测代替同一均衡的处理。

主计算将所有创新载荷设为σ=0.001，以检验小扰动局部近似；原配置σ=0.01保留，另输出尺度对照。ρ依次为0.8、0.75、0.7、0.8。σ作用于对数成本或组合权重的logit，不是每个可观测变量统一增长同一百分比，详见[shock审计](11_shock_audit.md)。

## 3. 一阶方程与稳定子空间

代码先利用技术、静态需求和会计恒等式消去部分控制，再对余下原条件和状态转移取导数。一阶系统可写为

$$
0=f_x\widehat x_t+f_y\widehat y_t+
f_{x'}E_t\widehat x_{t+1}+f_{y'}E_t\widehat y_{t+1}.
$$

令内生控制的局部政策为$\widehat y_t=G\widehat x_t$，条件均值状态转移为$E_t\widehat x_{t+1}=H\widehat x_t$，则核验

$$
f_x+f_yG+(f_{x'}+f_{y'}G)H=0.
$$

广义Schur分解选取稳定及中性子空间；这里有17个相应根，图映射满秩，无0/0不定广义特征值对，图映射条件数约1.00053。最大矩阵残差为1.11086×10⁻¹⁴。3个根等于1，与财富分配有关；其余根在单位圆内。

这不是全部互补分支的动态秩证明，也不是全球唯一性证明。规范中的“36+L+R组标量KKT条件与未知数计数相同”仍只是必要计数，不升级为全模型独立秩。

[消元对照测试](../tests/test_projection_equivalence.py)独立对L/R四种边界以及非均衡点进行对照，检验消元后的残差、财富/队列转移与原条件评估器一致。不是把求解器自己报告的收敛标记当作等价性证据。

## 4. 为什么不能直接在线性系统中确定期货头寸

在无风险锚，$P_{t+1}=F_t$。对I、D、F三条期货最优条件线性化，三行定价切线相同，数值秩为1，持仓方向导数为零。因此“确定性锚选h=0”并不意味着随机经济中h=0最优。

抵押约束松弛时，各主体都满足

$$
F_t=\frac{E_t(M^j_{t,t+1}P_{t+1})}{E_tM^j_{t,t+1}}.
$$

将I与D、F的定价式分别相减，得到两个条件：

$$
\operatorname{Cov}_t\!\left(
\frac{M^D}{E_tM^D}-\frac{M^I}{E_tM^I},P_{t+1}\right)=0,
$$

$$
\operatorname{Cov}_t\!\left(
\frac{M^F}{E_tM^F}-\frac{M^I}{E_tM^I},P_{t+1}\right)=0.
$$

用一阶消费创新与价格创新的载荷计算这些领先二阶协方差；给定组合，重新求解一阶均衡，再迭代组合，使两个条件成立。净期货供给为零，第三个头寸由清算确定。得到

$$
(\bar h^I,\bar h^D,\bar h^F)
=(0.1356829883,-0.0947312762,-0.0409517121).
$$

缩放后的协方差差异残差约2.73907×10⁻¹²，两个未缩放差异约为−7.94×10⁻¹⁹和−1.52×10⁻¹⁸。选定组合下，零风险锚的抵押余量约0.193443。

**这一步仅用二阶条件选择零阶组合，尚未得到完整二阶决策函数。** 头寸的一阶状态斜率仍不被一阶系统识别，本候选取零；不能把这一计算约定解释为头寸一般不随状态变化。组合符号由当前合成参数与风险收入结构产生，也不能当作产业必然多头或下游必然空头的结论。原理与Devereux–Sutherland的组合扰动方法相符，见[文献核验](10_recent_literature.md)。

## 5. 冲击响应的定义与结果

两条线性路径具有相同的冲击前状态，只在当期一个创新上相差+1；未来创新按同一个概率分布积分。在一阶系统中，未来创新条件均值为零，所以响应可以按$H^h$传播。**这是随机预期的条件均值，不是假设主体预先知道未来不再有冲击。**

CSV的百分比列是$100\,\Delta X/\bar X$，不是对数百分比或非线性指数还原值。主表σ=0.001；成本类对应当期成本水平约提高0.10005%，组合权重不是直接需求量。

| 创新 | 当期P，% | 当期F，% | 当期Q，% | 当期J，% |
|---|---:|---:|---:|---:|
| 终端组合权重 | 0.004277 | 0.007594 | 0.030144 | 0.046654 |
| 经营成本 | 0.028928 | 0.019380 | −0.018542 | −0.172558 |
| 开工成本 | −0.001070 | −0.000339 | −0.003711 | −3.058804 |
| 抵押要求 | 0 | 0 | 0 | 0 |

开工成本冲击下，第0、1、2月有效产能的变化为零；第3月首次改变有效产能，变化约−0.042237%。第6月约−0.094902%。这一时点来自继承的L=3建设队列。当前工资、产量与需求可以先调整，因而现货价并不需要从第0月开始单调上涨。对这些一般均衡反馈作定量渠道贡献归因，还需要重新求解反事实。

σ=0.01时线性J当期变化约−30.588%，说明该合成参数下投资弹性较大。该文件仅作振幅审查，不能据此宣称行业投资将下降约三成。

抵押冲击为零是当前分支下的经济结果：抵押要求不改变松弛约束的乘子或其他一阶条件。未来可能绑定的状态、更多融资渠道或其他参数下的结果尚未求得。本轮没有验证非线性金融放大或正库存缓冲。

一阶下$\Delta E_tP_{t+1}-\Delta F_t=0$，数值误差约2.04×10⁻¹⁶。它不说明真实风险溢价不存在；相反，协方差风险补偿首先出现在更高阶。不能从本批图给出时变风险溢价、价格发现因果结论或福利排序。

## 6. 将局部政策代回完整非线性原条件

不是只核对线性矩阵。代码在4类冲击的37个时点共148个状态，将同一政策代回原非线性评估器，每点枚举16个后继。

| 创新载荷σ | 最大原条件残差 | 域错误数 |
|---:|---:|---:|
| 0.0005 | 9.27067×10⁻⁶ | 0 |
| 0.001 | 3.68964×10⁻⁵ | 0 |
| 0.002 | 1.46108×10⁻⁴ | 0 |
| 0.01 | 3.37269×10⁻³ | 0 |

前两次振幅翻倍，残差分别约扩大3.980和3.960倍，符合一阶近似的二阶截断误差。σ=0.001的148点均未达到完整非线性验收阈值1×10⁻⁸，因此验证记录不会把它们标为非线性通过。绝对残差采用本项目归一化单位，不应解释为相同数值的福利损失。

在主振幅的这些采样状态中，最小消费约0.00199979，最小产能余量0.466466，库存对偶差0.0310228，借款余量0.399997，抵押余量0.193419，F本期及16个后继的净财富保持正值。这支持当前采样域的局部分支可行性，不是无限期随机路径保持在该域的证明。

## 7. 为什么拒绝非线性投影候选

以稳定一阶解和已选组合为初值，在同一零库存及其他约束松弛分支上进一步拟合含18个控制的对数仿射政策，保留完整非线性期望和状态转移，未求全部互补分支。正式记录采用35个配点、64个独立随机盒内点（种子20261126），函数评估上限350。

| 项目 | 结果 |
|---|---:|
| 35个配点最大原残差 | 1.88957×10⁻⁷ |
| 64个外样本点最大原残差 | 1.05516×10⁻⁶ |
| 条件均值状态转移谱半径 | 3.41561 |
| 优化器达到收敛条件 | 否，达到350次评估上限 |
| 真实随机转移路径，种子71126 | 第3月的16个后继全部违反抵押约束 |
| 非线性候选验收 | 拒绝 |

失败系数、点位审计与路径记录保存在验证JSON的nonlinear_projection_attempt中，不作为成果IRF的数据源。不剪裁头寸或财富、不删除失败分支、不因配点残差变小而宣布收敛。验证方法参考MMW21与AGS22对原始均衡条件、约束和策略一致性的要求；这些文献的算法性能不构成本模型的收敛证明。

## 8. 财富单位根与后续计算边界

3个财富单位根受到创新激发：将创新载荷传播1000步后，剩余载荷秩仍为3，再应用一次转移矩阵的差异约9.46×10⁻¹⁴。因而本线性系统不能支持平稳无条件协方差及相应FEVD。

这不等于证明完整非线性、带借款/抵押约束的模型不存在平稳分布。下一步应在经济上正确的可达状态域内求约束切换和财富政策，检验跨期可行性；若引入金融主体利润分配、进入退出或其他财富回归机制，必须重写相应主体预算并给出行业依据，不能为方便求解每期重置财富。

有限期局部IRF已经成立；全球非线性GIRF、时变风险溢价、平稳财富分布、结构估计和中国贸易/外部支付扩展仍未完成。
