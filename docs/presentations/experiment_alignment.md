## 两条并行工作线

模型线：冻结既有结构 → 演示参数下完整随机求解 → 独立状态点重算原始条件、边界和预期 → 记录失败状态。

数据线：确认来源和许可 → 统一商品/单位/统计时点 → 建立观测对应 → 划分校准参数和待估参数 → 识别预检查。

两条线具备条件后，做合成参数恢复，再进入真实估计。估计阶段对候选参数保持模型解与观测似然一致，不把一组演示政策用于全部参数。

## 第一轮实验的三个问题

1. 在明示参数和可行初值下，七个当期条件、全部价值递推和同政策预期能否同时满足？不能只看程序是否结束。
2. 需求、成本、风险承受环境分别扰动时，P/F/Q/D/I/C/J/K如何联合变化？先看物量守恒、持仓净和及边界，再解释经济含义。
3. 去掉某一机制后，结论是否变化？每个对照需重写相应目标/条件并重新求解；无期货对照不能直接令F=P。

## 出问题时怎样处理

不收敛：先检查时点、尺度、初值、活动约束和算法，再判断模型可行域或经济设定是否需要修订。

估不稳：先查数据口径、观测噪声和参数识别，必要时减少自由参数；不是立即增加新部门。

结果不符合数据：辨别是样本、测量、参数还是机制问题；用独立检验和稳健性作判断，不为拟合而反复调式。
