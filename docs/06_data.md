## 参数怎么处理

先固定或外部校准商品边界、名义人民币价格/利率口径、损耗ell、退出delta、L/R/g_a、能力和CAPEX单位。折现不再是任意固定的beta：选择月度利率系列与基准后，按E02计算b_t，并由同一利率状态转移生成d_(t,s)。这些均不设为未经核查的“文献行业常数”。omega需采购/排产证据，缺少时不能同时自由估eta_s、eta_c、omega。

候选识别包括eta_s、eta_c、alpha、nu、kappa、chi、omega_B、库存h/xi/I0、外部过程系数、λ_g/λ_τ/γ_ζ及有效风险承受能力。先归一化g和ζ的观测尺度，避免状态载荷与行为系数重复自由缩放；再缩减参数集，不直接对全部参数安排MCMC。

期货溢价主要出现T=1/a_I+1/a_D+1/a_f。只有P/F而无对应持仓，通常无法仅凭该关系区分三类风险厌恶；条件方差、敞口和风险容量还可能相互混淆。先限定参数集，再做解析等价、数值秩及合成恢复。

## 数据验收记录必须包含

来源机构、授权范围、原文件哈希、原变量定义、商品品级、单位、频率、统计月份、发布时间/首次可用时间、下载时间、版本、转换步骤、缺失标记和模型映射。无法确认的发布日期不能补成假日期。

先定义训练/验证时间和信息可用性，再估计；没有协议冻结，不能把已经看过的数据称为真正前瞻样本。

## 2026-11-05｜本轮数据映射决定

以下决定将本轮文献核查与 [全条件闭合](14_complete_conditions.md) 落到 E31 的观测映射和识别门槛。它们是后续资料验收的约束；当前仍无已验收的 V2 估计样本或新增行业参数点值。

### 1. 年度、全球弹性不直接变成中国月度碳酸锂参数

ELAST25 的全球年度矿产弹性明确以一年作为短期，并区分实际消费与含库存变化的总需求、矿端与炼制端供给。该口径不能直接设为本模型的月度 `eta_s`、`eta_c`，也不能将年度弹性除以12完成转换；元素锂与指定品级碳酸锂的商品边界同样需要处理。文献数值只作为方向、期限差异及敏感性范围的参考，参数约束须另有中国月度同口径证据。供给弹性也不能直接取倒数设为负荷曲率 `nu`。定位：[ELAST25 证据卡](13_literature_20261105.md)，[出版社正文](https://link.springer.com/article/10.1007/s13563-025-00537-3) Methodology 式(1)—(3)、消费/需求与矿端/炼制端比较、p.994；本模型口径见 E05、E25、E31。

### 2. 工程成本中年化资本与投资支出分账

COST25 的工程比较包含年化资本成本；其平均总成本不能整体输入短期可变成本 `m`。构建 E02 成本锚时应分开原料、运输、可变加工、固定支出和资本项，再将项目资本支出按新增能力与付款/开工时点映射到 `p^J`。同一资本成本不得既通过平均成本进入 `m`，又在 E07 的投资支出中重复计入；`chi` 和 `omega_B` 仍需独立调整或拥挤成本依据。定位：[COST25 证据卡](13_literature_20261105.md)，[出版社正文](https://advanced.onlinelibrary.wiley.com/doi/10.1002/aenm.202501813) §4.1、Figure 3、§4.2.1—4.2.3；本轮未执行其补充成本工作簿。

### 3. 真实期货合约、逐日盯市与到期结算的映射待核准

E26 的 `h(P'−F)` 是一期、完全匹配现货标的的模型支付定义。真实数据必须逐合约记录报价时刻、到期月份、适用规则版本、品级与地点、交割方式及结算价定义，并区分逐日盯市现金流、保证金占用和到期交割结算。月均现货价不能自动充当交割结算价，连续主力序列也不能未经换月映射就充当本模型的 `F_t`。

本轮依据为 [GFEXCLEAR25、GFEXQA 证据卡](13_literature_20261105.md)：[广期所结算规则英文参考译本](https://www.gfex.com.cn/en/TradingRules/202601/00e76b0dcdcc466abb0e9d798431a7f5.shtml) 第6、16—19条，以及 [官方《碳酸锂期货及期权40问》](https://www.gfex.com.cn/gfex/tslpzzl/202307/db1ea6ce118342ba886e5ef5b667ebe1/files/e57713398e094ca8af27b7ba49f82259.pdf) Q25。现有核验仅覆盖原机构索引返回的相关文字，直接页面/PDF打开超时，完整现行中文规则及2026年修订附件尚未核完；因此制度映射未通过验收。若匹配后的结算标的与本模型 `P'` 不同，须明确基差与协方差，再重审 E23、E24，而非直接沿用完美套保消去结果。详细边界见 [制度对照](05_evidence.md)。

### 4. 价格关系主要约束总风险容量及其与方差、敞口的组合

E27 中 `T=1/a_I+1/a_D+1/a_f`，风险溢价为 `mu_P−F=v_P(alpha_I I−C)/T`。相同 T 的不同风险厌恶三元组给出相同约化价格与实物条件，却可对应不同持仓分配。仅有 P/F 时，不得把三类风险厌恶同时视为可分别识别；若未来均值、条件方差或采购敞口缺少独立约束，T 本身也未必已被单独识别。下一步需匹配可对应主体的分类持仓或独立风险资本资料，并先检验参数组合等价与合成恢复。

结构依据：[ELV19证据卡](13_literature_20261105.md)及 [2018-01-26作者稿](https://www.ceremade.dauphine.fr/~ekeland/Articles/ELV.pdf) §3.3—3.5；本项目的聚合识别结论与零方差持仓选择边界见 [全条件闭合第6—8节](14_complete_conditions.md)。文献机制不构成中国碳酸锂三类风险厌恶参数的现成估计。a_i以次期人民币收益为单位，若货币单位由元改万元或更改风险目标的折现时点，须同步重标度，不能直接比较原参数数值。

### 5. 采购承诺 C 仍是缺少独立观测验收的模型变量

C 必须对应本期确定、下一期耗用的采购/排产承诺。验收须确认可撤销性、履约月份、品级、覆盖主体以及与实际耗用 D、库存 I 的重复关系。订单、产销计划、仓单或期货持仓不能直接替代 C；若从同一物量恒等式反推 C 与其他数量，也不能把这些残差当作彼此独立的观测。`omega` 的分组占比及 `eta_c` 的识别因此仍保留为 P0 缺口。

D25 支持需求调整随技术、车型和期限而异，但其结果不直接确认本模型“一月且不可撤销”的承诺机制或中国月度采购份额。定位：[D25 证据卡](13_literature_20261105.md)，[2025-06-19作者稿](https://phuongmho.github.io/LiDemand.pdf) pp.11—13、式(3)—(6)及p.17 Table 1；本模型承诺时点和实物计量见 E05、E20、E23、E25、E29。

### 6. 九个外部状态的映射与识别

E01的x＝(g,e,r,ζ)和z^id是宏观过程加行业余项；统计VAR或独立块核先定义条件分布，因果“货币政策冲击”还需单独识别。Hammoudeh、Nguyen、Sousa（2024）研究中国货币政策与全球商品价格的传导，为利率、汇率与不确定性通道提供机制背景；其季度全球商品证据不能直接当作中国月度碳酸锂过程系数。Boehm、Kroner（2026）关于经济消息与全球金融周期的结果为风险压力/风险容量通道提供依据，同样不直接确定γ_ζ或a_f。核验层级及适用边界见 [近期证据卡](13_literature_20261105.md)；原来源：[Energy Economics](https://www.sciencedirect.com/science/article/pii/S0140988324004754)、[Review of Economic Studies](https://academic.oup.com/restud/article-abstract/93/1/215/8105821)。

E02的成本映射为m＝exp(z_m^id)(m^D+E^FX m^U)：本地人民币成本m^D不再乘一次汇率，美元成本m^U按人民币/美元汇率换算。工程路线权重、投入系数与基准美元价格须形成可复核成本桥。当前没有独立美元原料价格状态；若改为逐项随机投入价，应增广状态并重算L+R+12的维数。τ(t)是预先给定的确定性路径；从同一价格或耗用序列同时自由估τ、g和z_A^id会增加趋势归属的识别问题。

年化报价利率按发布机构的复利约定转为月度。名义价格与名义利率保持一致；若研究实际量，需统一平减与实际折现映射，不能只改其中一项。采用线性r过程时必须给出支持，使1+ī^(m)+r>0；任何观测截断或变换都要作为明确模型改动，不在程序内部静默裁剪。

### 7. 观测核、发布日期与风险溢价

H_t按已验收的变量、单位和可用日期固定；无C观测时删除相应行。P/F可用正价格对数，I允许零值而采用水平观测。E31已选定独立高斯测量核e_t^obs∼N(0,Ω_obs,t)，测量噪声在时期间独立，并与结构创新及初始状态独立，Ω_obs,t为给定半正定矩阵。这是统计闭合选择，尚不是行业估计结果；估计前须冻结其量纲、参数约束与缺测处理，不能让自由测量误差吸收全部清算或时点偏差。

模型风险溢价是E_tP_(t+1)−F_t，实现价差P_(t+1)−F_t还含条件均值为零的预测误差；当期基差F_t−P_t又是另一量。分别报告三者的定义、期限和样本映射。真实合约未匹配前，不把回归残差直接解释为结构风险补偿。
