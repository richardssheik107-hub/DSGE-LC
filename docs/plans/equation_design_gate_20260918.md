## 3. 对原四项比较的影响

- CMP_NOINV4检验的是原增长失衡记忆指数的增量；不是实物库存是否存在的检验。
- CMP_COSTFEEDBACK15检验矿价自主过程限制；不替代完整同单位成本映射或工具变量识别。
- ROB_COMMON57检验重新定标，不解决同比q与月度p/c的结构变换差异。
- FUT_DAILY_INCREMENT可以作为独立金融应用保留，但当前优先级低于老师关心的方程基础；不让它代替理论论证。

原比较协议v1保留作草案，不无痕重写。D02设计冻结须引用本门槛；若选了新的经济边界/观测，应另建protocol v2和新实验ID。不要先实现三个变体再事后寻找经济理由。

## 4. 最小数据需求不是“搜集越多越好”

| 需要支持的假设 | 优先数据/资料 | 处理方式 |
|---|---|---|
| 需求派生关系 | 同一制造层产量/出货、动力/储能用途、化学体系与LC投入资料 | 只选互不重叠口径；不能把装车/电池/材料多层相加 |
| 路线成本 | 工艺产量、精矿投入/收率、采购定价时点、能源试剂等同单位成本 | 授权公开年报/工程资料优先；未知系数不可凭试用账号推断 |
| 物理库存 | 同制度期初期末库存、产量、LC净进口、耗用/转换 | 正文必须包含未观测部分；不以残差硬造真实库存 |
| 价格观测 | SMM对应产品历史方法论、品位、税/贸易、报价时点 | 不把另一个指数2026规则当作v1历史规则 |
| 完整CGE若被要求 | 锂行业可分离的投入产出/SAM、要素/家庭/政府/外部账户、numeraire与闭合 | 属新范围，现5变量不能直接填出这些账户 |

“不把数据当拖延理由”不等于“现有数据足以识别所有新方程”。先说清缺哪个结构量，再针对性获取。原商业v1不改变；公共可读不等于可以再分发。

## 5. 进入D02的必要条件

本次只做示范代数测试，不代表这些条件全部满足。新模型的局部识别、合成恢复、真实估计、后验诊断与经济比较仍按后续阶段执行。代码PASS不等于理论合理；理论合理不等于现实数据识别；导师批准不由工具替代。
