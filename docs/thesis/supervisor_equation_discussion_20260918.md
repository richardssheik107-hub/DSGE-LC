# 下一次组会：从碳酸锂产业关系到方程（讨论稿）

**本次实际完成的是文献/产业核对与代数示范；没有声称已经估计一个新的多部门均衡模型。** 旧M0保留作经验半结构基线，其结果只能按原假设解释。

## 1. 对问题的直接回应

不能把生猪的能繁母猪、饲料、居民消费和猪周期逐一改名。拟先以锂盐企业和材料制造企业的决策为中心，把上游资源价格、产能约束、投入需求、贸易及库存连起来。是否需完整CGE而不是局部多部门关联模型，请老师确认；会议摘要中对老师心理的评价不作为指导要求记录。

## 2. 检索后最重要的四个修正

| 原说法 | 本次修正 |
|---|---|
| 动力电池装车就是需求 | 装车只锚定部分最终应用；实际材料耗用/采购还涉及生产层、储能、技术与库存 |
| 矿价乘汇率就是成本，可直接与LC价格相减 | 精矿与碳酸锂“每吨”不同；需投入量、收率及其他路线可变成本，才能构造经营价差 |
| 产量增长减需求增长就是库存 | 标准化同比差额只是压力指数；物理库存必须使用同商品同单位流量守恒 |
| 把需求、成本、供给放进价格式即有定价机制 | 需明确市场出清、价格调整或加成定价如何闭合，不能把三套独立关系同时强加 |

## 3. 可以当面推导的一条供给关系

给定既有产能K，生产商选Q最大化：

`(P^e-m^e)Q - gQ²/2 - kappa(Q-Q_prev)²/2`。

内点结果：`Q=[kappa/(g+kappa)]Q_prev+[1/(g+kappa)](P^e-m^e)`。

这清楚解释生产惯性、价格激励和成本抑制。它是当前提出的简化计划问题，不是完整跨期最优化；产能上限、未来调整项和同单位m必须说明。现在用同比q和月度价格涨幅，不能省略观测变换便认作该式。

## 4. 一条市场闭合示例

同单位供给`Q=rho Qprev+alpha(P-m)`、耗用`U=A-epsilon P`、净进口N与目标净补库J暂给定：

`Q+N=U+J` → `P=(A+J-N-rho Qprev+alpha m)/(alpha+epsilon)`。

因此价格反应系数受到供需参数约束，不是任意加减几个变量。下一步需要确定当期Q是否可调、库存J如何决定，而不是先多跑一轮后验。

**闭合**：短期产量是否当期调节、库存采用明确目标还是跨期选择？

**证据**：已有五条核心变量哪些只作代理，哪些必须补充路线成本、下游生产/耗用或同制度库存？
