# R3：从生猪例文学习写法与版式

2026-09-17。依据用户提供的35页生猪研究修改稿及其Word文档结构；不是期刊或学校官方模板。原参考稿全文、图片与作者身份不上传本仓库。

## 本轮改什么

当前重写入口：[reference_style_manuscript.md](reference_style_manuscript.md)。旧九章[advisor_draft.md](advisor_draft.md)和R2生成器保留，供已验收旧版本复现；不是要求在两个源文件中重复编辑。

| 例文组织 | R3对应内容 | 写法调整 |
|---|---|---|
| 一、引言 | 产业背景、问题、研究路径 | 从锂价为何涨跌切入，不从代码/审计阶段切入 |
| 二、文献综述 | 资源供需、库存与识别、估计与评价 | 按问题归纳，说明本文位置，删除重复技术免责声明 |
| 三、理论分析框架与模型构建 | 机制、状态、观测、数据、方法 | 先产业机制，再方程，再变量与估计；保留半结构定位 |
| 四、实证分析 | 参数→IRF→FEVD→历史→预测→外部与期现 | 每组先说现象，再解释传导，最后给必要限制 |
| 五、结论与政策建议 | 结论与启示 | 无政策结构参数，故不复制精确政策反事实或福利建议 |

本稿约8,620个中文字符、五个主体部分，定位为参考式研究稿，不等于已经满足学位论文篇幅。原九章完整版可按导师要求再展开，不用字数或相似度代替论文质量。

## 从实际参考文件得到的版式

参考Word的页面为A4，顶/底25.4mm，左/右31.75mm，正文双栏、栏间约7.5mm；可见表4采用三线表，表题位于表上，图题位于图下。R3保留页面、表图等通用特征，但按用户后续要求将当前正文改为单栏。

正文10.5pt、首行两字缩进；中文宋体类、英文Times类，缺字体必须明确记录替代。当前大标题、摘要、正文、宽表、公式及主图均为单栏，数字右对齐。R3固定行距17.5pt、表字9pt、图注9.5pt、注释8.5pt及灰度线型是为了可读性作出的设计选择，不宣称每个值均逐项等同原稿。

三条横线分别为表顶1pt、表头下0.5pt、表底1pt；不加竖线或整表网格。参数表将可信区间分为两列，长解释移至表后。正文保留表1—6，完整版本另含附录表A1；表2从私人冻结数据生成。

## 不复制什么

不复制例文句子、作者、机构、数值、图形数据或未经本项目实施的四部门DSGE/混频/Harvey周期。例文中的断裂交叉引用、表与正文数字差异、小字过密图和Theil解释问题不照搬。本文保留自己的R1结果、后期歧义、残差份额和预测不占优结论。

R3少了重复的版本日志，不代表取消限制：数据/模型限定在方法节，结果特有限制在对应结果旁，完整诊断移至附录，许可与版本置于审阅说明/来源清单。
