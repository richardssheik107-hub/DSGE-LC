## 本包要交付

补成可给导师首轮讨论的资料，而不是直接跑新模型：

1. 定义三个研究问题、暂定商品/地区/频率、生产路线与直接耗用层；分清用户要求和待导师决定的范围。
2. 精读实际采用的目标函数/产业映射原文；每条关系标明原式、文献启发自设、工程账、恒等式或自行推导，未读到的数学对象不补造。
3. 从生产商目标、材料厂目标和 E24 清算重算 C0，统一参考点、偏离量、输入与冲击；逐项解释矩阵元素和输出。使用现有代码作为对照，而非复制就称复核通过。
4. 明确最小观测映射 P/Q/R/Y/m/I 等的单位与可得时点；不要求一次补齐全部数据，但列出独立信息和需要校准的工程量。
5. 写产能投资、库存行为两张增量卡，列替换哪些式子、增加哪些预定/前瞻变量、需要什么求解和数据。
6. 更新导师包和真实验证记录；只提交自己的明确文件。完成材料不等于已发导师或已经批准。
