## 1. 从什么问题重新出发

暂用工作题目《碳酸锂价格波动的影响因素与定价机制研究》，最终题名、产业范围和学位类别由学生与导师确认。先回答三个相连的问题，而不是先决定需要多少状态或多少公式：

1. **价格怎样形成？** 同一商品边界下，下游实际耗用、上游成本与供给如何共同决定价格，哪些因素影响是条件性的？
2. **波动为什么持续？** 短期产量调整、长期投资投产、库存决策能否形成不同期限的传导，而不是用一个额外周期项吸收所有误差？
3. **解释是否经得起数据检验？** 哪些参数可区分、哪些归因依赖假设、模型对历史变化和未用于训练的预测对象有何支持及限制？

现货产业模型是主干。期货联合定价、真实混频、回收寿命和完整一般均衡都不是默认毕业必需品。选择动态随机部分均衡还是完整 DSGE，必须讨论账户、目标函数、市场闭合与数据；不能因仓库名字含 DSGE 就宣称已经实现一般均衡。

## 2. 怎样学生猪稿，哪些不照搬

参考稿展示的研究逻辑是：现实价格问题与产业机制 → 文献 → 主体行为/行业关系 → 动态均衡 → 状态空间和观测 → 估计 → 冲击分析、分解与预测 → 结论。我们学习这一逻辑，不推断作者真实工作的逐日顺序，也不把参考稿的“首次”、发表状态、参数、预测准确率和周期份额当成本项目证据。

| 学习的环节 | 碳酸锂课题怎样落实 |
|---|---|
| 先说明产业问题 | 从实际 LC 商品、成本路线、材料耗用与时序出发 |
| 主体而非变量拼盘 | 生产者与直接耗用者先建立决策，储存/投资可由现有主体承担，不凑部门数 |
| 找慢变量 | 核产能建设队列与调整摩擦；不是把母猪变量换名成锂产能 |
| 由经济关系得到转移 | 每次保留完整目标/约束/最优条件，再消元或求理性预期解 |
| 模型与数据分层 | 月度、同比、流量、存量和首次发布时间逐项映射 |
| 用实证回答问题 | 新参数、新结果、新版本；允许弱识别或预测不占优的结论 |

生猪稿原件是用户提供的修改稿，不上传原件。本库对照在 [hog_paper_comparison.md](../references/hog_paper_comparison.md)。正文结构另按[硕士论文提纲](THESIS_OUTLINE.md)组织。

## 3. 两次确认，不把导师同意当成数值验收

**确认 A：研究与理论范围。** 不等全文读完、不等数据全补齐、不等 MCMC。用几轮方程包让导师决定问题、主体、生产时点、库存闭合、是否需要投资和最终主干。

**确认 B：可估版本。** 在确认 A 之后，完成观测算子、稳态/约束解、可观测性与参数识别预检、合成恢复和正式协议，再放开真实估计。导师同意研究方向不能替代这些检查。前期澄清能减少返工，但不能承诺后面的识别和抽样必然很快。

这两个门槛之前可以进行文献精读、数据定义核查、求导、方程残差测试、小规模合成仿真、求解器试验和理论写作；不可将未批准的候选模型批量真实估计后再挑好看的结果。

## 6. 文献、公式与数据怎样一起走

文献按机制精读，不按数量交差。现有 45 来源与 28 候选关系仅作入口，原 18/20 来源列表有重叠；不相加，不自动插入毕业论文。每条最终公式注明：原式复用/文献启发后自设/工程核算/恒等式/由前式推导，记录读到的原页和适用条件。

**最低数据界面从 RB01 同时建立，不拖到模型已经很大之后。** 不要求立刻把所有变量补满，但必须知道 P 是哪种价格、Q 是哪条路线、Y 是哪个制造层、I 是何种库存，哪些是独立观测、哪些共享原料输入。现有 C0 的 a、alpha、单位成本及库存范围尚不能被一个潜状态自动补齐。

新数据集根据新边界确定样本、频率与变换，不强制 57 期或旧 scaler；也不覆盖 Data Freeze v1。旧 p/c 月涨幅、q/d 同比、n 失衡指数不可直接改名为水平经济量。同比需完整聚合或滞后观测算子。

## 7. 复杂度与扩展的边界

产能投资是优先讨论的慢供给机制，库存是并列的关键候选，但不是“必须先估好 C0 才能推导下一轮”。理论扩展可以先做，真实批量估计等最终范围和技术验收后再进行。

贸易、第二路线、需求细分、回收、期货与混频只在它们回答主问题且具有可说明的信息支持时进入主模型。回收若缺样本前电池批次，只保留已实现再生产量条件输入；原矿进口与成品进口分账。完整一般均衡若被导师明确要求，另补家庭/要素/外部账户等闭合，不在当前骨架上改个标题。

停止扩展的判据是：已覆盖主问题的关键传导；新增机制的不可替代作用可说明；参数与观测的约束可识别；求解可行；导师范围已定。**不是“达到 28 条”。** 状态空间维度还随建设队列、观测滞后和价格输出的表示法改变，不能把公式组数当状态数。
