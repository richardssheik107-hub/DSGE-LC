# 参数识别预检：不能被MCMC消除的几种等价关系

2026-09-20｜基于 `0b5e3cf8138ac7a861c3e0758c23608f601ca6c2` 的局部内点模型。以下代数是本次推导，不是把Iskrev的结论直接套到LC。数值检查使用原纯合成fixture，未读取商业原始数据、未估计参数、未做参数恢复。

## 1. 材料需求截距：Abar和v只能识别差值

目标函数只出现 `(Abar+z-v)Y-bY²/2-aPY`。对任意常数d：

$$\bar A'=\bar A+d,\qquad v'=v+d,$$

目标和所有均衡路径不变。即使能观测Y、K，也不能依靠该模型分别估这两个截距。应改用 `dbar=Abar-v` 一个净需求截距；如需分别解释，须用独立资料固定其中一个。把v设成零只能是参数化归一化，不能声称现实非LC成本为零。本次只提出修改建议，没有改原模型代码。

## 2. 未观测材料吨数时：a、b和需求尺度一起变化也能等价

对任意r>0，取：

$$Y'=rY,\ a'=a/r,\ b'=b/r^2,\ A'=A/r,\ v'=v/r,\ \sigma_D'=\sigma_D/r.$$

则 `a'Y'=aY`，材料收益/成本和LC实际耗用均不变。若只观察P、Q、I、m，而不独立观察Y或固定工程a，就无法区分这些参数化。

优先补实际材料产量及工程投入强度；装车GWh、同比增速、材料库存量不能直接当Y。材料产量的独立观测可以打破这一个等价方向，但不是所有参数识别问题的万能解决方案。

## 3. 未观测产能时：gamma与投资成本共同存在尺度等价

在所有比较路径都处于严格Q<K的当前局部内点范围，令：

$$K'=rK,\quad J'=rJ,\quad B'=rB,\quad
\gamma'=r\gamma,\quad p_K'=p_K/r,\quad\chi'=\chi/r^2,\quad W'=W/r.$$

则：

$$\frac{\gamma'Q^2}{2K'}=\frac{\gamma Q^2}{2K},\quad
p_K'J'+\frac{\chi'}2J'^2=p_KJ+\frac\chi2J^2.$$

能力递推和内点最优条件同时保持等价；P、Q、I、Y、m可以完全一样，而K/J不同。独立K、启动能力或可信工程成本尺度至少需要一个锚。只给这些参数强先验会选择等价集合中的位置，不会使数据获得本来没有的信息。

**边界：** Q≤K的硬约束改变后，全球触边区域可能不同；这里不主张这是整个非线性约束模型的全局对称性。也不主张观测K就识别了所有投资参数。

## 4. 库存h/xi：稳态不能分开，动态有可能分开

$$\bar I=\frac{\xi}{h+[1-\beta(1-\ell_I)]\bar P}.$$

固定beta、ell、Pbar/Ibar后仍有一条h/xi组合曲线。单个稳态不能分别决定二者。局部动态还包含 `xi/Ibar²`，因此独立库存变动可能提供额外信息；不能把“稳态不识别”夸大为“任何数据都绝对无法识别”。

建议先以可核现金仓储/保险费用限定h，固定或做有依据的beta和物理损耗情景，再讨论xi。h不应重复计入已经由beta体现的同一融资利息。库存调查覆盖未知时，xi的解释必须连同覆盖映射一起检查。

## 5. 当期库存和净补库不是两份独立信息

若观察 `Iobs_t=I_t+e_t`，并由同一序列计算

$$J^{obs}_t=I^{obs}_t-(1-\ell_I)I^{obs}_{t-1},$$

则误差为 `e^J_t=e_t-(1-ell_I)e_(t-1)`。即使e_t独立同方差tau²，仍有：

$$\operatorname{Var}(e_t^J)=\tau^2[1+(1-\ell_I)^2],\quad
\operatorname{Cov}(e_t^J,e_{t-1}^J)=-(1-\ell_I)\tau^2.$$

不能把I和它的差分同时作为相互独立白噪声观测来提高“样本信息量”。Qtotal、Q和从差额构造的R也有同类问题。

## 6. 本次实际做了哪些数值检查

使用原L=2合成fixture、原内点求解器，假设理想月度同步且同商品的 `P,Q,I,m` 可观测、零测量误差。Q是参考块而非未经拆分的全国总量；这些理想数据并没有在现实仓库被全部实现。

只解析证明了上面列出的等价关系。Jacobian的其余数值秩损失不能凭空命名为某个已证明机制；15个方向也不因此被宣布在真实样本上已识别。全部参数是否能在最终似然中识别，仍需最终观测/误差/时间聚合和多点检查。

可观测秩5/6表明当前六维表示在该观测设计下并非六个状态都可分别恢复；这不等于完全不能预测观测量，也不证明模型的全部经济设定错误。固定参数的状态可观测性，与未知参数的可识别性是两个问题：加K后状态秩满，Abar/v的等价仍然存在。
