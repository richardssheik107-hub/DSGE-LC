## 3. 这组确定性结果说明什么

L=3、R=2的主锚中，产量约0.21820719、开工0.02102880、有效能力0.68531459、P=F约0.55637857。它们都是归一化合成值，不是吨数或人民币行业预测。四类消费为正，原条件最大残差约2.22e-16；四种L/R组合最大约1.11e-15。

债券分配固定为W/I/D/F=(-0.05,-0.10,-0.05,0.20)，净额为0。F正消费来自所持债券利息，另外三类承担相应负债。没有新增净资源。共同β下Euler不唯一决定资产分配；零风险合约不唯一决定持仓，h=0只是一种选择。库存为0由严格正库存对偶量支持，并非强制删除未来随机库存。

缩减的4维实物稳态系统数值雅可比秩为4；这不是完整动态系统或金融持仓系统的满秩/BK检验。内部在建拥挤使全局凹性不能自动成立，所以记录为平稳KKT候选，不宣称全局最优或唯一均衡。

## 4. 条件评估器与随机政策的区别

`evaluate`给定当前状态/选择以及全部条件分支，检查当前原条件、后继转移和基本可行性。它不自动证明每个后继也满足其自己的最优条件，更没有在整个可达域寻找一套一致政策。

本轮做了一个具体反例：开启4个创新后，仍在所有状态使用同一确定性锚决策。原点条件可通过，但将16个首期后继分别作为当前点、再各枚举16分支，全部被拒绝，最大残差约0.00398007。因此“单点预期残差小”不能替代完整随机固定点。这是有限样本拒绝一个错误候选，不是全域政策验收。

代码当前采用共同β、0<δ<1、正下游活动分支、非零有效能力和ε≠1。规范中异质β、δ=0等更一般的理论参数分支未全部实现；稳态器还固定在正开工、产能不绑定、零库存的选定分支，不是自动搜索所有稳态。

| 识别与估计 | 先模拟恢复，再做真实观测与后验；不继承旧预测或组内FEVD |
