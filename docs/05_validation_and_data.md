# 05｜冲击、风险精度、数据与验收

本文件规定新DSGE怎样呈现随机机制、怎样区分数值证据与经济结论、怎样从月度模型走向识别和实证。设计基于[统一蓝图](03_dsge_blueprint.md)，组内稿的冲击响应、分解、估计和预测链条作为研究组织参考，不继承其数值成绩。

## 1. 必须体现S，但不靠增加冲击数量

最新LC版本已经有结构随机性。新模型仍必须说明信息集、创新分布、持续系数、冲击幅度、进哪条原始条件、通过什么主体反应、如何影响价格及资源，而不是只写 $\varepsilon_t$。

| 首版冲击 | 原始入口 | 第一层经济作用 | 重要后续反馈 |
|---|---|---|---|
| 终端组合偏向创新 | omega的有界映射，最终组合器 | 改变LC密集型产品的相对需求结构 | 下游产品价格和LC耗用、工资、家庭消费、开工和预定采购 |
| LC真实成本创新 | m的正值映射，生产资源成本 | 改变上游边际与总资源支出 | 产量/库存/价格、企业主消费与SDF、未来建设 |
| 金融抵押要求创新 | kappa的正值映射 | 改变每单位期货头寸所需的自有安全资产 | 金融消费/净值/头寸、其他主体套保、风险溢价与实物选择 |

第三类不叫“波动率冲击”。若要研究波动率，另设创新条件方差过程，并检查高阶项或非线性求积是否保留它。新闻冲击需要新的信息到达结构，不能把已知技术趋势改名为随机技术创新。

旧宏观g、利率r、净进口N不自动继续各有独立AR：总景气和安全利率在新封闭模型中内生，进口在开放阶段配预算后恢复；世界价格和世界利率可以是小型开放DSGE外生条件。旧九维核的计算经验可复用，冲击经济含义需要重新登记。

## 2. 冲击响应的计算与展示

对同一政策G、给定冲击前状态s和冲击事件e，使用

$$
GIRF_h(s,e)=E[y_{t+h}\mid S_{t^-}=s,e_t=e]
-E[y_{t+h}\mid S_{t^-}=s].
$$

未来创新按原概率律继续发生，两组使用共同随机数以降低积分误差。原离散两点核可精确枚举首期其余冲击；后续继续用同一核，而不是把所有未来不确定性删除。

至少选择正常库存/资本充裕、低库存/产能紧、金融抵押接近绑定的可达状态。状态先由合格政策模拟获得，再冻结选择规则；不得事后挑选最显著图形。所有失败状态保留并报告，不能clip或删除后只展示有效路径。

图应同时展示P、F、$E_tP_{t+1}$、风险溢价、当前基差、Q、I、J、有效产能、灵活耗用、采购承诺、各主体消费、F净值/头寸/抵押乘子。风险溢价定义为 $E_tP_{t+1}-F_t$，基差若采用F−P须在图注固定，不能混用P−F。

每图注明模型版本、真实/合成参数、单位、冲击规模、起点、h=0时点、求积/模拟次数与误差。现有0.00025的载荷只相当于约0.025003%的直接乘数变化，不得称为1%。

旧对称两点实验把无条件均值定义为正负条件均值的平均，所以正负响应按定义互为相反数；不能用该定义本身证明经济响应没有方向不对称。研究不对称性需要清楚设计冲击事件、基准分布和不同幅度，保持与模型概率律的关系。

## 3. 风险效应需要高于数值误差

新定价分解为SDF协方差项与抵押影子楔子。旧PE中风险补偿为vH/T；二者都不能只靠P、F的图形分叉判断。标准确定性稳态的一阶扰动通常不呈现相关风险修正；时变风险溢价的某些通道需要更高阶或固定非零风险的非线性解[SGU04，AND11/12]。

固定风险投影的多项式次数与扰动阶数不同。只要积分中保留随机后继，仿射价格政策也可以产生非零条件方差。反过来，使用三次多项式不自动保证金融溢价有足够精度。

必须分开报告四种误差：

1. 政策近似和原始经济残差；尤其预算、定价、库存和抵押互补。
2. 求积/蒙特卡洛误差；首期完全枚举不消除其他误差。
3. 浮点差分消减误差；两个约为2的价格相减得到1e-12量级响应时尤其重要。
4. 参数/数据不确定性；只有经过估计或校准不确定性分析才能画相应区间。

金融响应应同时从 $E[P']-F$ 与新定价分解重算，在提高政策精度和积分精度后保持方向与主要量级；须有事前规定的误差上界和信号相对误差门槛。若小于可分辨范围，结论应是“该设置下未能可靠分辨”，不能放大纵轴后宣称显著。

旧成本冲击在第0月的两种风险溢价算法出现约−1.41e-13与+1.65e-13的异号，已足以提示这一风险；这是本轮查到的数值限制，不是新模型的预测。

## 4. 分层验收，防止概念越级

| 层级 | 实际检验 | 能支持的结论 |
|---|---|---|
| 仓库一致性 | 路径、版本、来源、归档哈希、文档与机器记录 | 组织和证据没有混版 |
| 会计闭合 | 各预算相加、LC/劳动/债券/期货清算、最终资源残差 | 没有漏账、重复账、无对手方资金 |
| 局部数学 | 成本导数、影子递推、个体价格接受、KKT边界、状态推进 | 实现符合当前原始问题 |
| 确定性锚 | 全部预算、FOC、资源与终值选择 | 指定参数下有一组一致的确定性候选 |
| 随机政策 | 同政策预期、独立原式、可达后继、固定点更新、精度比较 | 在声明域和误差标准内得到随机均衡近似 |
| 风险机制 | SDF/约束分解、跨状态响应、重新求解的反事实 | 该机制在指定模型和参数中的作用 |
| 识别与真实估计 | 合成恢复、敏感度/秩/似然、数据与先验诊断 | 参数和冲击得到怎样的数据支持 |
| 外推与福利 | 额外域、制度变体、适当阶数的福利比较 | 仅在通过相应附加审查后成立 |

任何层级都不能由上一层自动宣告完成。方程数等于未知数不证明独立、存在或唯一；BK局部条件不证明全域存在；轻量测试通过不等于完整随机政策已重算。

## 5. 观测选择与经济识别

| 新结构对象 | 优先观测或外部限制 | 关键识别问题 |
|---|---|---|
| P、一期F及相对价格 | 同口径现货、分到期日合约、最终品价格/平减指标 | 主力连续不能未经处理直接当一期模型F；名义价格须一致转实值 |
| Q、K、建设爬坡 | 月度产量、可用产能、投产公告与爬坡记录 | 名义年产能不等于月度可用能力；L/R不能仅由价格拟合 |
| I和损耗/服务 | 同边界库存、库存覆盖与仓储数据 | 统计口径缺货不能当零库存；便利收益须有经济服务解释 |
| D^s、C及下游技术 | 排产、订单、下游产量和投入强度 | 无承诺数据时，灵活/预定份额和各自弹性可能不能分开识别 |
| 成本m与工资 | 原料、能源、加工及工资分账 | 工资、汇率和进口投入重复进入成本会造成虚假多冲击 |
| 企业主风险与F财富 | 分类持仓、风险账户/可替代融资指标、抵押制度变化 | 只用P/F一般不足以分开偏好、财富和资本约束 |
| 家庭/最终部门 | 消费、劳动、收入和LC密集型终端指标 | 不能用外给收入过程替代已声明内生的家庭预算 |
| 跨境部分 | LC与原料贸易、价格、汇率和融资支付 | 流量与外部资产必须在同一边界内闭合 |

表中是数据需求，不表示这些指标已经拿到或获准发布。经营者消费等变量可能缺少直接观测，可由有限外部限制校准，但需报告识别范围。不能为了同时估计每个新参数而任意增加“冲击代理”或测量误差。

观测模型写成 $y_t^{obs}=\mathcal H_t(S_t,G(S_t);\theta)+e_t$，而不是默认所有变量的对数线性组合。I或h可为零/负，不能无条件取对数。测量误差的分布、协方差、与结构创新独立性及发布时点都需要声明；观测噪声不代替结构冲击。

先做模拟数据恢复：检查合成样本能否分辨需求、成本、抵押创新，以及gamma、初始财富、抵押系数、技术份额等参数。价格拟合很好但参数互相补偿时，应减少自由参数或增加有经济意义的观测。随后才做真实估计[SW07作为研究链条参考，非本项目参数来源]。

## 6. 混频应该怎样借鉴组内文献

组内稿的混频目标与缺测处理值得保留，但先明确基本经济时钟。当前LC生产、采购与队列自然按月建模。日度期货在月内随信息变化，不是把同一个月度状态重复观测多次就能完整描述。

有三项需要分开：观测发布日期造成的缺测；流量和存量如何聚合；潜在经济状态是否在月内推进。H_t行掩码主要处理第一项，不能自动解决后二项。

第一份估计应使用一致月度观测，约定价格月末/月均、产销月内合计、库存月末、利率复利转换、合约到期映射。只有月度结构与识别通过后，才决定是否采用日度潜在状态加月度聚合、月内信息状态，或仅把日价作测量信息。任何选择都需重新定义转移和观测，而非复制组内稿16维或31×16的文字表述。

## 7. 论文与答辩怎样体现改进

理论部分沿组内稿顺序展示四个关键连接：家庭目标如何产生各自SDF；LC作为中间品怎样进入最终需求；企业/金融预算怎样合成资源约束；冲击怎样改变实物和风险分担。随后给同一模型版本的确定性锚、随机解验收、三类冲击和机制反事实。

可以准确地对老师解释：原工作已经包含随机状态与期货风险机制；本次将完整预算和资源清算纳入，重新从主体最优条件推导期货定价，再用能够分辨风险信号的随机求解来展示冲击。不能现在就说这些新计算已经完成。

所有数字应标为本次运行、历史报告记载、手工推导或文献原结果之一。组内稿的FEVD和预测方向准确率、旧LC半结构结果以及最新PE合成图，均不进入新DSGE的“实证结果”章节。
