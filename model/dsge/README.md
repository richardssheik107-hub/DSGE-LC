# 当前可计算层 确定性锚与局部随机理性预期

对应模型 `LC_DSGE_EQCHAIN_20261126`，规范为[重建方程链](../../docs/06_equation_chain.md)。本包实现新的所有者预算和消费SDF，不导入历史PE求解器。已完成确定性原条件核验，并求得选定分支上的局部一阶随机RE政策与冲击响应。

## 可复算入口

从仓库根目录执行：

```bash
python -m unittest discover -s tests -v
python scripts/validate_equation_chain.py
python scripts/validate_shocks.py
python scripts/solve_stochastic.py
```

默认不更新证据。完整记录更新和实验性投影重跑见[04实现记录](../../docs/04_implementation_plan.md)。所有参数为合成归一化值，尚未校准中国碳酸锂行业。

## 原条件评估与确定性基础

```python
from model.dsge import solve_anchor

anchor = solve_anchor()
assert anchor["audit"]["passed"]
```

`evaluate(state, choice, branches, parameters)`由调用方提供当前与未来选择，核验完整创新核、状态推进、原条件和后继基本可行性。它是政策结果的独立审计工具，一次通过不构成全域随机解。

确定性锚采用共同β和安全总回报1/β；债券W/I/D/F=(-0.05,-0.10,-0.05,0.20)净额为0。F消费由债券利息支持，其他主体承担相应负债。锚计算将所有创新载荷置零，并选I=0、h=0；库存有严格对偶差，零风险头寸与财富分配不唯一。

给定开工后解析恢复建设/爬坡队列与影子值，再解工资、现货价、产量和开工四个未知量。原评估器从未缩减条件复核，主锚最大残差约2.22e-16。内部在建拥挤未自动保证全局凹性，因此不把平稳KKT候选称为全局最优或唯一均衡。

## 局部随机解

`LocalProjection`保留四类所有者、持续财富、旧合约和16后继；代数恢复市场/技术/预算条件，没有重置资产。局部分支固定I=0且其余约束乘子为0，由此从18维规范状态中去掉继承库存，保留17维。

`solve_linear`对该分支的一阶理性预期系统做广义Schur分解。当前计算有17个稳定或中性根，一阶矩阵残差约1.11e-14；其中3个财富根为1且受到冲击激发，所以不报告遍历财富分布或平稳无条件方差。

三类期货原条件的零风险一阶切线秩为1，无法唯一选出持仓。`select_portfolio`用领先二阶SDF协方差相等条件选择零阶I/D/F头寸约(0.13568299,−0.09473128,−0.04095171)。这是组合的最低非零风险选择，不是完整二阶政策。头寸斜率在一阶近似中不识别，当前候选将其设为0并明确记录。

`linear_irfs`计算四类正创新相对无条件均值的0—36月局部响应。主结果σ=0.001；原配置σ=0.01只作幅度敏感性。未来创新在一阶条件均值中积分掉，不是假定未来消息已知。当前κ通道在松弛局部分支为0，库存保持0，一阶风险溢价变化恒为0。

## 原非线性误差与拒绝规则

局部近似候选重新进入原非线性评估器：σ=0.001时148点评估最大残差3.6896e-5，均未通过1e-8，且无域错误。σ两次翻倍的误差比约3.98和3.96，符合一阶截断特征。这与一阶矩阵已求解是不同层次的结果。

自由斜率正风险投影虽把配点原残差降至约1.89e-7，但未达到1e-8，条件均值转移谱半径3.4156，并在随机可达路径第3月出现16个后继全部抵押违规。该候选已拒绝，不用于当前IRF或经济结论。审查同时看原条件、留出点、动态和全部正概率后继，不以优化器消息或一个配点误差代替验收。

实现仍限定正消费、正下游活动与有效能力；L=1和R=0已测试。完整随机域不变性、约束切换、二阶风险溢价、全局横截条件、开放经济支付和真实估计未完成。规范、结果与所有限制详见[09](../../docs/09_stochastic_computation.md)及[验证JSON](../../docs/validation/local_stochastic_20261126.json)。
