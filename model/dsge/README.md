# 当前可计算层：原条件评估与确定性锚

对应模型 `LC_DSGE_EQCHAIN_20261126`，规范为[重建方程链](../../docs/06_equation_chain.md)。本目录建立新的 DSGE 经济条件，没有导入历史 PE 求解器。

## 可复现入口

从仓库根目录执行：

```bash
python -m unittest discover -s tests -v
python scripts/validate_equation_chain.py --write-report
```

第二条命令重新计算合成锚、原条件、边界、导数和错误候选拒绝证据，并更新[验证记录](../../docs/validation/equation_chain_20261126.json)。参数是任意归一化的合成值，未校准中国碳酸锂行业。

## 模块职责

| 文件 | 实际实现 |
|---|---|
| `parameters.py` | 参数域、单位对应的合成数值、固定初始债务分布、四冲击核参数 |
| `state.py` | 建设剩余期索引、爬坡及成熟转移、已承诺采购、债券和未结算合约继承 |
| `shocks.py` | 四个独立对称两点创新的全部16个分支、正值及 logistic 映射 |
| `economy.py` | 下游技术、真实成本、四份所有者预算、最终资源及财富诊断 |
| `residuals.py` | 对给定当期选择与未来分支计算原始 FOC/KKT、预算、出清和转移残差 |
| `steady_state.py` | 共同 beta、指定净零债务分布下的确定性平稳 KKT 锚 |

核心接口：

```python
from model.dsge import solve_anchor, evaluate, Branch

anchor = solve_anchor()
audit = anchor["audit"]
assert audit["passed"]
```

`evaluate(state, choice, branches, parameters)` 的未来状态和选择由调用方提供。程序核验创新核完整、状态转移相符，并从未来消费统一生成各主体 SDF。当前全部期望使用同一组未来选择和概率。它不负责找到满足所有状态条件的政策函数，不能将一次通过残差审查称为随机均衡已求解。

## 确定性锚如何闭合

固定共同 beta，安全总回报为 `1/beta`。给定 W/I/D/F 债券面值 `(-0.05,-0.10,-0.05,0.20)`，债券总额严格为零。F 的消费来自其债券利息，另外三个主体支付对应利息；没有外部净值重置。四个创新载荷在本次确定性计算中设为零，`z=0` 不被称为正风险经济的无条件均值。

选择 `I=0`、`h=0`；库存的严格正对偶值验证角点。零风险期货收益为零，净额为零的多种头寸均可满足原条件，测试明确展示这种不唯一性。债务分布也是给定选择，未声称由模型唯一识别。

给定投资 J，平稳建设与爬坡队列解析恢复；影子价值由原包络递推恢复。数值联立求解工资、现货价格、LC 产量和开工四个对数未知量，其余当期量由技术、需求和预算恢复。随后通用评估器从全部原始条件重新计算残差，包含求解时没有直接使用的资源条件及所有 KKT。

四维缩减稳态 Jacobian 的秩报告只适用于该分支，不能推论完整动态系统的秩或 BK 确定性。内部建设拥挤项可能破坏联合凹性，因此该结果是满足完整一阶条件与会计条件的平稳候选，不是全局最优或唯一均衡的证明。

## 当前适用域和未实现事项

本实现限定成熟能力非负且有效能力为正、两个最终部门正产出、下游灵活耗用/劳动/预定采购严格正、所有者消费严格正；成熟能力为零但爬坡队列提供正能力的状态可以评估。它不在 Cobb–Douglas 投入为零的停产点计算 `1/C`，不裁剪非法路径。`L=1` 和 `R=0` 的队列边界均实际测试。

有限分支评估包括未来 F 净值和消费正性，以及后继控制的投资、库存、容量、债务和抵押可行性检查；这不构成全域后继不变性证明。测量方程、随机政策求解、正风险 GIRF、开放经济支付扩展、全局横截条件和真实估计没有在本目录实现。零风险稳态路径有界且 beta 小于1，其贴现尾项沿该指定路径消失；这不是对随机政策尾项的验证。

专门的错误政策测试把确定性锚冻结为常数、打开四个创新，在原点和全部16个首期可达后继分别审计；每个审计又完整枚举16个下一期分支。原点可以通过局部条件，但16个后继均被拒绝。这说明单点原条件通过不能证明整条随机政策有效；有限采样发现错误也不等于已经完成全域政策验收。

构造与队列时点显式继承冻结 PE 提交 `4c28915abf32a493ea11ddd262f3a30f57c458c6` 中 E10—E16 的结构经验；预算、消费 SDF、下游技术及抵押条件重新实现。旧 E27 均值—方差闭式不作为新条件调用，旧测试和数值结果也不继承。
