## 版本与研究边界

当前候选编号为 `LC_DSGE_DESIGN_20261126`。首选为有最终品和碳酸锂中间品、建设爬坡与库存、有限类型家庭及受限资产参与的真实经济 DSGE；先完成闭合与确定性锚，再做随机均衡和风险定价。有限类型经营者扩展用于保留套保和有限风险承担这一研究重点。

央行、名义黏性、国外部门和混频估计各自需要相应经济与数据依据。它们按明确接口逐步引入；中国碳酸锂的实证版本必须处理跨境流量和外汇成本，不能把封闭经济诊断基线直接称为中国完整估计。

组内未发表 Word、授权数据和论文全文均不在本仓库发布。参考稿与新模型的差异、尚未完成的推导和验证见上述文档。
